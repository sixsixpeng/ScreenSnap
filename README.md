# ScreenSnap

ScreenSnap 是一个基于 Python、PySide6 的 Windows 优先截图与贴图工具。程序启动后常驻系统托盘，没有常驻主窗口。支持混合 DPI 多显示器截图、单选区原地编辑、多区域截图、矢量标注、图像变换、多格式保存、剪贴板多类型贴图和独立置顶贴图。

本文同时作为**用户操作手册**和**开发维护指南**。界面、快捷键、配置项或工作流发生变化时，应在同一改动中更新相应章节和测试说明。

## 快速开始

需要 Windows 和 Python 3.10 或更高版本（安装时勾选加入 PATH）。在项目目录运行
[`start up.bat`](start%20up.bat)：脚本检查系统 Python；若缺失则中文提示并等待按键退出。
若 `.venv\Scripts\pythonw.exe` 缺失，脚本会删除旧 `.venv` 并重建；随后激活虚拟环境、
安装 [requirements.txt](requirements.txt)，最后以 `pythonw main.py` 启动托盘程序。
首次运行需要能访问 pip 包源；安装失败会显示原因并等待按键，不启动程序。

也可以手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

程序启动后会显示托盘就绪提示。右键托盘图标可快速截图、编辑剪贴板图片、打开图片、进入设置或退出；双击托盘图标开始自由选区截图。

依赖清单见 [requirements.txt](requirements.txt)。全局热键依赖 `keyboard`；Windows 的窗口边缘吸附还使用 `pywin32`。

## 操作手册

### 截图

- `F1` 开始自由选区。可在一个遮罩中创建多个矩形；按 Enter 或左键双击执行“截图确认后”设置（默认进入编辑器）。选择“仅保存，不打开编辑器”可改为直存。右键双击和快速保存按键 `S` 始终直接保存；未选区时按 Esc 退出截图。
- `Ctrl+Shift+F1` 选择整个虚拟桌面；`Ctrl+F1` 选择鼠标所在的当前显示器。
- `Ctrl+Shift+F2` 重用上次选区的位置和大小，在新画面中重新截图。显示器布局变化后若选区已不在桌面范围内，程序会提示。
- `Ctrl+F` 打开固定尺寸选区输入框；输入宽高后，在当前鼠标位置建立选区。
- 选区存在时按 `S` 可快速直接保存；可在“设置 > 截图 > 截图快捷操作”修改。快速保存沿用输出外观、格式、目录、剪贴板和保存通知配置。
- 默认进入编辑：开启“原地编辑”时，单屏单选区在截图位置打开原地编辑；多个选区、跨屏选区或关闭“原地编辑”时打开独立编辑器。“窗口编辑”按钮始终可手动打开独立编辑器。
- 注意：左键双击不是快速保存键，它跟随“截图确认后”设置；右键双击和 `S`（可在常规页改键）是无条件直存操作。
- 快速贴图默认按键为 `Space`，但功能默认关闭；在“设置 > 截图 > 截图快捷操作”启用并修改按键。启用后可直接把选区作为贴图打开，不进入编辑。
- 选区存在时，遮罩底部会显示“自定义尺寸”和“重新截图”；前者创建指定尺寸的选区，后者关闭当前遮罩并重新捕获画面。
- 拖动选区内部可移动；拖动四角或边缘中点可调整大小。选区接近屏幕或可见窗口边缘时会吸附。选中选区后使用方向键或 WASD 可微调位置。
- `Tab` / `Shift+Tab` 把选区切到鼠标下的窗口、分组容器或控件（由外到内逐层进入）；开启“自动选中窗口”后，开始截图即直接选中鼠标下的窗口。浏览器、Electron 等自绘界面可优先通过 UIA 识别已暴露的无障碍节点；未暴露节点时回退到顶层窗口句柄。
- 开启“移动鼠标自动识别”后，移动鼠标会以蓝色半透明块实时高亮下方的窗口或控件（取最内层），**左键单击即选中该区域**，按住拖动仍然手绘选区；想选外层窗口或父容器时按 `Tab` 逐层切换。高亮颜色和填充不透明度，以及识别刷新间隔，都可在“设置 > 截图 > 窗口与控件识别”中调整；默认使用 `#168CFF` 蓝色和 35% 填充不透明度，边框保持实色。
- “设置 > 截图 > 窗口与控件识别”提供识别总开关、自动选中、悬停高亮、UIA 优先级、悬停刷新间隔和祖先层级。默认开启 UIA：识别会先用 Windows 无障碍树读取浏览器、Electron、Qt/WPF 等自绘界面内部的按钮、标签和编辑框，需要安装 `uiautomation`（`python -m pip install uiautomation`）；未安装或查询失败时自动退回窗口句柄识别。UIA 命中后最多继续向下查找 24 层，并优先沿覆盖鼠标点的最小子控件下钻；“识别层级”控制的是 Tab 可切换的祖先层数，不控制这段向下搜索。仍无法读取未暴露给 Windows 无障碍树的自绘元素。本程序的截图遮罩与贴图会穿透识别，同进程普通窗口仍可作为目标。
- “设置 > 截图 > 遮罩与选区”可选择清透蓝、薄荷绿、奶油黄、樱花粉、淡紫等遮罩色预设，也可自定义颜色和不透明度；默认清透蓝 `#D9EDFF`、50% 不透明度。旧版深色/浅色选择会分别迁移为黑色/白色遮罩。
- “设置 > 截图 > 截图时机”里可设置**截图延迟**（0–5000 毫秒）：按下全局截图热键后先等待再抓画面，用于避开快捷键冲突造成的界面变化，或等待菜单、动画、网页渲染完成。托盘菜单发起的截图会自动再追加 150 毫秒等待菜单关闭。
- 多显示器截图使用虚拟桌面坐标，支持显示器负坐标；显示器之间的间隙也处于虚拟桌面矩形内。
- 截图提示显示首个选区的缩略图和选区总数，约 4 秒后关闭。提示、尺寸文字、十字线和放大镜不会写入截图。
- 单选区且完整位于同一显示器内时，默认进入**原地编辑**：不会打开新编辑窗口，而是在选区上直接显示编辑画布和紧凑图标工具栏。多选区或跨屏选区会自动回退到独立编辑器窗口，避免多画布和跨屏 DPI 坐标冲突。
- 进入原地编辑后不能继续新增选区，但可以拖动已有选区的角点或边中点调整大小；调整时会隐藏旧编辑层，释放鼠标后按新区域重新裁剪并重建编辑画布。调整选区会清空该区域已有标注，避免标注坐标与新截图区域错位。
- 原地编辑会立即保存一次初始截图；点击保存或双击空白会覆盖同一个文件并退出；放弃会关闭编辑层但保留初始截图文件。
- 未选区、调整选区和原地编辑时均可显示放大镜；原地编辑按 Esc 直接退出本次截图，不返回选区状态。“显示鼠标”开关只在本次截图存在带/不带鼠标两版时可用。
- 原地编辑不提供裁剪工具；需要裁剪图片时可在独立编辑窗口中使用。取色后紧凑工具栏的颜色按钮仍只显示色块。

遮罩深浅、锚点样式、十字线颜色和宽度、放大镜、光标捕获及通知均可在设置中调整。遮罩不透明度 0% 表示不遮盖选区外区域，100% 表示完全遮盖。

### 编辑器

#### 标注工具

标注工具包括选择、画笔、记号笔、文字、箭头、矩形、椭圆、橡皮擦、马赛克、取色和裁剪。编辑器默认大小为 1200×760。各工具的颜色和样式在“设置 > 编辑器”的工具专属分组中配置；画笔、矩形、椭圆和橡皮擦分别提供独立参数和预览。橡皮擦直径可设为 10–100，默认 30；编辑器工具栏切换到橡皮擦时使用相同范围。工具栏“更多设置”显示当前工具的颜色与预览；吸管取色后写入进入吸管前最近使用的可调色工具独立颜色，并复制色值到剪贴板。取色工具显示滴管光标。“显示鼠标”位于标注区域。单选区原地编辑使用紧凑图标工具栏，按钮名称与说明通过多行 tooltip 展示。

“更多设置”随当前工具显示对应参数。单区原地编辑工具栏保留“自定义尺寸”和“重新截图”，因为它仍负责当前截图选区；“窗口编辑”打开的独立窗口只负责编辑，不显示这两个截图控制按钮。截图选区阶段，每块显示器顶部提示下方仍提供“自定义尺寸”“重新截图”和“窗口编辑”三个独立小按钮；窄屏会缩短按钮标签。提示文案保持单行。

**吸管取色的具体反馈位置**：先选择矩形、箭头、文字等有颜色参数的工具，再选择“取色”并在图片上左键取样。取样色会写回进入吸管前最近使用的可调色工具，而不是固定写入画笔：例如从矩形切到吸管，取样后矩形颜色改变，画笔颜色保持原值。颜色会显示在工具栏“当前工具颜色”色块和“更多设置”的颜色行，并以 `#RRGGBB` 复制到系统剪贴板；切回原工具即可继续使用该颜色。紧凑原地编辑工具栏只显示色块，详细颜色设置仍在“更多设置”里。

#### 浏览、缩放和变换

- 右键或中键拖动画布，或按住空格拖动，可平移画布；右键单击已有标注则打开标注菜单。
- 鼠标滚轮默认上下滚动；按住 Ctrl 或 Alt 滚轮改为横向移动。纵向、横向滚动步长均已调小；滚轮不缩放画布，也不缩放选中标注。
- 用选择工具拖动选中标注的边框或缩放手柄时，原标注内容保持可见并随拖动实时缩放，不会被白色选择框遮住；独立窗口编辑和单区原地编辑行为一致。
- 画布显示缩放通过编辑器下方的滑块或百分比输入控制，范围为 1%–800%。显示缩放不改变导出图片分辨率。
- 图像旋转区域的第一个按钮是“重置角度”：应用任意角度旋转后可恢复旋转前状态；编辑图像或标注后该入口会禁用。左右旋转 90°、旋转 180°、水平/垂直翻转及任意角度旋转也在该区域。
- 任意角度旋转支持旋钮预览和数字精确输入；取消恢复原状态，确认后记录为一次可撤销操作。旋转和翻转会同步变换现有标注。
- 撤销、重做和重置操作位于编辑区域。重置用于恢复原始截图状态。

#### 输出

最终图片外观设置位于“设置 > 保存与输出”，包括透明圆角、半径、边框和阴影。边框覆盖图像最外沿，不留原图窄边；圆角与边框边缘使用超采样抗锯齿。编辑器工具栏“输出”组中的“外观”按钮也可打开同一套控制和最终预览；从任一入口修改都会保存并同步到设置页和已打开的编辑器。

点击“外观”打开预览面板，再点一次同一按钮即可关闭；按 Esc 或点击面板外也会关闭。圆角、边框和阴影分别由面板中的开关控制，数值控件会即时更新预览并同步保存。单图编辑和截图原地编辑使用同一套行为。

快速贴图默认按键为 `Space`，但功能默认关闭。可在“设置 > 截图 > 截图快捷操作”启用并设置一个按键组合；选区存在时按下会直接打开贴图，不进入编辑。

圆角选区遮罩、编辑画布预览和标注合成均使用抗锯齿；最终保存、复制和贴图输出使用超采样圆角蒙版。源截图保持完整，编辑时仍可关闭圆角或调整半径。

- **保存**：保存 PNG 到手动保存目录，按保存设置中两个独立开关复制图片和/或文件路径到剪贴板，然后退出编辑器；默认复制图片、不复制路径。
- **贴图**：自动保存当前合成图，将其作为独立置顶窗口打开，然后关闭编辑器。
- **放弃**或 Esc：关闭编辑器，不保存当前编辑结果。
- 双击空白画布执行保存操作。保存成功提示可显示最终图片缩略图。

原地编辑中的输出按钮含义更直接：**贴图** 会保存当前合成图、创建贴图并退出截图编辑；**保存** 会覆盖当前初始文件，按相同剪贴板开关复制内容并退出；双击空白画布执行同样的保存动作。初始自动保存不修改剪贴板，显式点击“复制图片”始终复制图片；**放弃** 会退出但不覆盖修改。选区尺寸调整不会反复触发自动保存；单张原地编辑不显示“关闭全部”按钮。

单张截图默认可能进入原地编辑，多张选区或跨显示器选区使用独立窗口。两种编辑器里的“贴图”都是独立于“保存”的动作：会先按自动保存目录保存当前合成图，再创建一张置顶贴图，最后关闭编辑界面；仅点“保存”不会创建贴图。若要从文件开始制作贴图，可从托盘选择“从文件打开新贴图”；若要编辑已有贴图，在该贴图右键选择“编辑”，修改后点“贴图”创建新贴图，原贴图不会被覆盖。原地编辑的“窗口编辑”按钮是将同一选区转到独立窗口继续编辑，不是贴图按钮，也不会创建第二张截图。

编辑器的滚轮和按键行为也会显示在画布下方的操作提示中；支持当前快捷键的按钮和菜单项会显示绑定提示。

### 贴图窗口

按 `F3` 的“尚未贴出”列表与 `Ctrl+Alt+Left` / `Ctrl+Alt+Right` 的图片历史是两套导航：F3 逐次创建尚未显示过的旧图片；上一张/下一张在一个可复用的历史贴图窗口里换图。到达历史边界时不会创建空贴图；关闭 F3 创建的贴图后，该文件可再次由 F3 打开。历史源于自动保存目录，移动或删除目录内文件会影响可打开条目。

贴图窗口在退出时保存屏幕位置、实际宽高、相对原图的缩放倍率、旋转、透明度、锁定/置顶/点击穿透状态、分组和有效吸附关系；下次启动自动恢复。拖动和缩放后的状态经过短暂防抖写入，退出时再强制刷新。源文件删除或不可读取时跳过对应贴图，不恢复空白窗口。

**右键菜单逐项操作**：

- **重置大小**把当前贴图缩放倍率恢复为 100%，不改变位置、图片源或其他贴图；旋转过的贴图按旋转后的图像边界计算大小。
- **复制图像**复制源图像像素，不会把窗口边框、阴影、棋盘背景或屏幕缩放效果写进剪贴板。
- **替换此贴图**只替换当前窗口内容并保留位置和倍率；取消文件选择不做更改。**从文件打开新贴图**则新建独立窗口。
- **置顶**只影响当前贴图；**锁定**禁止拖动、滚轮缩放和方向键移动，但仍可从菜单解锁。
- **跟随/取消跟随**只切换当前吸附目标的移动同步；**解除吸附**同时清除目标与跟随。目标隐藏时暂停，恢复后继续；目标关闭则解除。贴图跟随为单向关系，拒绝形成循环。
- **透明度滑块**即时调整当前贴图；**点击穿透**让鼠标操作落到后方窗口，之后用 `Ctrl+Shift+T` 恢复所有贴图交互。

每张贴图都是独立窗口。左键拖动移动；滚轮缩放（倍率限制 0.1–10），缩放时短暂显示当前百分比；方向键或 WASD 每次移动 1 像素；Esc 关闭当前贴图。贴图默认描边、阴影和选中光晕可在“设置 > 贴图 > 贴图外观”配置，页面预览会即时反映描边、阴影、光晕开关及光晕强度。描边和阴影设置影响新建贴图的默认值；光晕强度范围为 0–100%，默认 30%。

拖动贴图时会自动吸附对齐：靠近屏幕工作区、其他可见应用窗口或另一张可见贴图的边缘（默认 8 逻辑像素内）即贴合，贴图目标优先于普通窗口；吸附瞬间沿图像外沿显示一圈青色虚线。按住 `Alt` 拖动可临时取消吸附，方便像素级摆放。贴到应用窗口后默认跟随该窗口移动；贴到另一张贴图后默认也会跟随，位置按吸附时的相对偏移同步。贴图间关系保持单向并拒绝形成循环；目标贴图关闭后自动解除跟随。目标窗口最小化或隐藏时暂停跟随但保留吸附关系，恢复后继续跟随，只有窗口真正关闭才自动解除吸附。可在“设置 > 贴图”关闭贴图间跟随，也可在右键菜单按目标分别开关跟随或直接解除吸附。

右键菜单提供锁定/解锁、重置大小、复制图像、从文件打开替换此贴图、从文件打开新贴图、描边开关、阴影开关、置顶开关、跟随吸附目标/取消跟随、解除吸附、关闭当前贴图、透明度滑块及点击穿透。替换会保留当前窗口的位置与缩放；取消文件选择不会更改贴图。锁定后不能拖动、缩放或用方向键移动。点击穿透后无法从贴图本身打开右键菜单，使用 `Ctrl+Shift+T` 恢复贴图交互。描边/阴影右键菜单只控制当前贴图是否显示，颜色、宽度和强度由全局设置控制；选中光晕开关和强度由“贴图外观”设置控制。

**右键菜单逐项操作**：

- **重置大小**把当前贴图缩放倍率恢复为 100%，不改变位置、图片源或其他贴图；旋转过的贴图按旋转后的图像边界计算大小。
- **复制图像**复制源图像像素，不会把窗口边框、阴影、棋盘背景或屏幕缩放效果写进剪贴板。
- **替换此贴图**只替换当前窗口内容并保留位置和倍率；取消文件选择不做更改。**从文件打开新贴图**则新建独立窗口。
- **置顶**只影响当前贴图；**锁定**禁止拖动、滚轮缩放和方向键移动，但仍可从菜单解锁。
- **跟随/取消跟随**只切换当前吸附目标的移动同步；**解除吸附**同时清除目标与跟随。目标隐藏时暂停，恢复后继续；目标关闭则解除。贴图跟随为单向关系，拒绝形成循环。
- **透明度滑块**即时调整当前贴图；**点击穿透**让鼠标操作落到后方窗口，之后用 `Ctrl+Shift+T` 恢复所有贴图交互。

截图图片提示在 Windows 上优先使用 Win11 原生图片 Toast，缓存本地 PNG 作为 hero 图片；点击 Toast 会定位已经保存的文件。Toast 线程不会阻塞 Qt 界面，点击事件切回 Qt 主线程读取最新文件目标，因此截图刚完成、初始保存稍后才结束时也能使用正确路径。无法导入/发送原生 Toast 时回退到应用内图片预览；非 Windows 平台始终使用应用内预览。贴图和一般状态继续使用托盘文字提示。通知是否出现仍受“设置 > 常规 > 通知总开关”和对应分类开关控制。

## 历史功能点与验收用例

本节把历史会话中提出的功能要求集中留档，作为用户手册之外的回归清单。当前行为以本 README 的操作手册和“已知限制”为准；已明确标为未支持的项目不视为完成。

### 功能点索引

- **应用、配置和通知**：Windows 优先的 PySide6 托盘应用；首次启动生成默认配置，设置修改即时持久化；全局快捷键可录制、清除并检查冲突；启动、截图、保存和贴图通知可按类别控制。托盘与任务栏菜单提供截图、剪贴板图片编辑、打开图片编辑及打开新贴图入口。
- **截图和选区**：支持混合 DPI 多显示器与虚拟桌面坐标、鼠标光标版本切换、延迟截图、多矩形选区、Esc 退出、固定宽高、上次位置重截。选区可拖动、八方向调整并用方向键或 WASD 微调；十字线、选区边框、遮罩透明度和放大镜有独立设置。窗口/控件选择支持 Tab 层级切换、悬停高亮和 UIA 优先识别。
- **编辑画布与标注**：选择、画笔、记号笔/荧光笔、文字、箭头、矩形、椭圆、橡皮擦、马赛克、取色和裁剪；工具参数分别配置并同步设置。文字支持字体/字号，箭头支持实心、空心和双向样式，马赛克支持常用效果与颗粒度，荧光笔支持半透明宽线。选择工具可二次选择、移动和缩放标注；橡皮擦按路径擦除标注而非整层；标注编辑受图片边界约束。
- **画布导航和图像变换**：画布初始居中；缩放由滑块/数值输入控制，滚轮默认垂直滚动，Ctrl 或 Alt 滚轮横向移动；右键、中键或空格拖动平移。旋转支持角度旋钮和精确输入、重置、透明空白区，且变换会同步处理标注；撤销/重做、裁剪边框样式与线宽可调。
- **保存和输出**：PNG/JPEG/WebP/BMP、质量、透明底色、命名模板、保存目录、图片/路径剪贴板选项；圆角、边框、阴影在设置与工具栏共用并预览。保存、贴图、放弃、双击空白保存等动作保持清晰区分；截图预览通知保留图片内容，初次落盘不重复发成功通知。
- **贴图与历史**：图片、文件、文字和颜色可贴为独立窗口；支持替换当前贴图、从文件新建贴图、F3 按时间顺序贴出尚未打开的历史图片、上一张/下一张、关闭后重新贴出、无效历史跳过。剪贴板历史跨重启保留。贴图可锁定、置顶、缩放、调透明度、吸附屏幕/普通窗口/其他贴图，并可跟随普通窗口或另一张贴图。管理面板提供多选、分组、整组显隐、关闭所选和关闭全部；Ctrl 点击后拖动可批量移动。
- **界面与维护约定**：工具图标使用明确语义并配文字/tooltip；快捷键提示与当前绑定同步；设置控件及按钮需对齐、不重叠、适应窗口宽度；功能、配置、注释、README、测试和打包资源随行为变更同步维护。项目采用模块化结构、标准 logging 和 PyInstaller 打包。

### 手动验收用例

1. **首次启动与配置**：删除测试用配置后启动，确认生成默认设置和托盘提示；修改快捷键、标注默认参数及通知开关，重启后确认设置保留，冲突快捷键有反馈。
2. **多屏截图与退出**：在不同缩放比例/负坐标显示器上分别截图，检查光标版本、遮罩、十字线和放大镜；空选区按 Esc 关闭，拖动创建多个区域后分别调整和微调。
3. **选区操作**：用固定宽高创建区域，使用 Tab/悬停高亮选择窗口或控件，调整角点和边中点；确认提示、尺寸文字、十字线和放大镜没有写进输出图。
4. **编辑器职责**：单区启用原地编辑，确认原地工具栏有“自定义尺寸”“重新截图”；点“窗口编辑”后确认独立窗口没有这两个截图控制项，但仍可完整标注、变换和保存。
5. **标注与画布**：分别使用文字、画笔、荧光笔、箭头、马赛克、橡皮擦、裁剪；检查参数记忆、图像边界限制、标注二次选择/缩放、撤销重做及小/大图缩放平移。
6. **图像输出**：测试任意角度旋转后重置、透明边角、圆角/边框/阴影预览；分别验证保存、贴图、放弃、图片与路径复制开关及通知图片预览。
7. **贴图管理**：贴图片、文件、文字和颜色；替换贴图并确认位置/缩放保留；连续 F3 依次取更早未贴图片，删除文件或关闭中间贴图后再次验证历史跳过/重用。
8. **贴图吸附、多选与分组**：拖动一张贴图靠近另一张贴图的边缘，确认对齐并跟随，再尝试建立反向关系确认不会形成循环；Ctrl 点击选择/取消多张贴图，拖动其中一张确认其余选中项同步移动；在管理面板多选后归组、改名、显隐和关闭所选；删除组应保留贴图。
9. **托盘与打包**：通过托盘菜单打开剪贴板图片/文件图片、新建贴图和设置；验证修改后的快捷键提示。分别用带控制台和无控制台打包启动，检查图标、资源、全局热键权限和启动提示。

### 未支持与待桌面验收

- 贴图互吸、贴图跟随、Ctrl 多选、批量拖动、批量关闭和分组均有自动化回归；桌面拖动手感及跟随视觉效果仍应手动验收。
- 混合 DPI、真实全局热键权限、Win11 原生图片 Toast 呈现和 PyInstaller 打包资源加载需要 Windows 桌面/打包环境验收。

## 设置和数据

设置窗口分为常规、截图、快捷键、保存、输出、编辑器、日志、贴图、剪贴板贴图和主题与外观十类：
每页按使用场景显示带标题的设置组，较长的页面可在页内滚动；同一组件的颜色、线宽及其他参数集中在同一组。设置值在内存中即时更新，配置文件写入合并 250ms 内的连续变化；关闭设置窗口或退出程序时会刷新未写入的最后一次变更。

- **常规**：启动与通知。
- **截图**：截图延迟/光标、截图确认后默认动作、原地编辑、快速贴图与快速保存、放大镜/十字线、窗口与控件识别、遮罩/选区外观及历史范围。悬停识别高亮默认采用 `#168CFF` 蓝色、35% 填充不透明度；遮罩默认采用 `#D9EDFF` 清透蓝、50% 不透明度，两者都可自定义。
- **快捷键**：全局热键总开关、截图类热键拦截、全局截图/编辑/贴图热键录制、清除和冲突检查。仅在截图遮罩中生效的快捷操作留在截图页，不与全局热键混在一起。
- **保存**：自动截图目录、手动保存目录、可选的按月/按日图片归档、PNG/JPEG/WebP/BMP 格式、质量、透明底色、文件名模板、保存后打开目录，以及保存时是否分别复制图片和路径。
- **输出**：最终图片的透明圆角/半径、边框和阴影；编辑器工具栏“输出 > 外观”弹层也能修改同一配置，实时预览最终结果。
- **编辑器**：默认标注工具、标注颜色/线型/线宽、填充、矩形圆角、荧光笔、文字、马赛克、编辑区边框和裁剪框参数。工具栏“更多设置”与本页共用配置，预览会即时刷新。
- **日志**：日志开关、ERROR/WARNING/INFO/DEBUG/TRACE 等级、按小时/每天轮转、按月份创建目录和保存位置。
- **贴图**：透明图像背景模式、默认描边/阴影外观、拖动吸附/跟随窗口和贴图管理缩略图。
- **剪贴板贴图**：文字卡片字体/字号/颜色/背景/宽度/最大行数；颜色识别、色值标注和色块尺寸；文件卡片路径、展示数量和宽度。
- **主题与外观**：跟随系统、明亮或黑暗主题。

### 设置入口与修改方式

所有页面中的控件会即时写入同一配置并保存。部分设置有多个入口：输出外观既可在“设置 > 保存与输出”调整，也可在编辑器工具栏“输出 > 外观”弹层调整；标注工具当前参数可在工具栏“更多设置”中修改，编辑器页提供相同的默认值和预览。修改任一入口都会同步其他入口和已打开的编辑器。

全局热键在“设置 > 快捷键”修改；截图遮罩内的快速贴图/快速保存键在“设置 > 截图 > 截图快捷操作”修改。设置页底部“恢复本页默认”只重置本页；窗口底部的“恢复全部默认”是最终手段，会先把当前设置备份成同目录的 `settings.bak` 再整体重置，“清理贴图会话”则删除贴图会话文件与私有缓存，方便从空白状态验证。

全局颜色模式位于“设置 > 主题与外观”，提供跟随系统、明亮和黑暗三种选择。它影响应用控件和窗口的调色板，但保留 Windows/Qt 原生控件与 tooltip 外观。设置项放在独立页面，是因为它跨越常规、截图、编辑器和贴图窗口；贴图吸附距离等只影响贴图拖动的偏好仍放在“设置 > 贴图 > 拖动与吸附”。

配置也可以通过设置窗口的 JSON 导入/导出功能备份或迁移；导入时会校验类型、范围和全局热键冲突。

### 配置参数详解

### 通知

Windows 优先显示带缩略图的原生图片 Toast；不可用时回退到应用内预览，其他平台使用应用内预览。
“设置 > 常规 > 启动与通知 > 通知方式”可在 Win11 Toast 与旧版通知之间切换，默认 Win11 Toast；普通状态消息也遵循该选择。Toast 不可用时自动回退；通知仍受总开关及分类开关控制。

Win11 Toast 模式下，截图图片提示缓存本地 PNG 作为 hero 图片，点击可定位已保存文件；普通文字消息也通过 Toast 发送。旧版模式使用应用内图片预览和系统托盘文字提示。无法导入/发送 Toast 时自动回退；通知仍受总开关和对应分类开关控制。

要提供可分析的 UIA 结构，在“设置 > 截图 > 窗口与控件识别”打开“记录 UIA 结构诊断”，再在目标程序上开始截图并悬停/识别目标；复制日志中以“UIA 结构诊断”开头的块。默认日志位于 `logs/YYYY-MM/app.log`（自定义日志目录则以设置为准）。输出最多 60 个节点；名称可能包含标题或文件名，分享前请检查并打码，诊断完成后建议关闭此设置。

标注颜色按画笔、矩形、椭圆、箭头、荧光笔和文字分别保存；工具栏“更多设置”显示当前工具对应颜色，设置项位于“设置 > 编辑器”内对应工具的专属组。画笔、矩形、椭圆分别显示独立预览。原地窗口编辑与独立单图编辑使用同一组独立颜色配置。截图选区转为贴图时，贴图图像左上角对齐选区原屏幕位置；快速贴图同样保留选区位置。普通图片编辑和剪贴板贴图没有原截图位置时，贴图图像中心默认对准鼠标指针。

### 编辑器结构

原地编辑器和独立编辑器复用标注画布、工具栏与输出效果，但保留各自的窗口生命周期适配：原地编辑依附截图遮罩和选区几何，独立编辑器负责普通窗口、多图和文件操作。调整共享控件时需分别验证两种上下文；避免复制两套画布/保存实现，也不要把两种窗口关闭和截图路由强行合并。

### 配置参数详解

以下参数名与 JSON 配置键一致。默认值是首次启动值；设置页修改后立即保存。参数表按设置页排列，每页内的控件按分组顺序列出；具体分组名称与界面一致。`hotkeys` 是动作到快捷键的字典，完整默认值见上方全局热键表。`last_capture_rect` 由程序记录上次选区位置和大小，不是用户设置。

### 贴图窗口

吸附选项位于“设置 > 贴图 > 拖动与吸附”：可关闭自动吸附，将触发距离设为 1–40 逻辑像素（默认 8），选择只吸附屏幕/工作区边缘、只吸附窗口与贴图边缘或两者都吸附。窗口跟随与贴图跟随可分别开关；跟随刷新间隔可设为 30–1000 毫秒（默认 120）。拖动时按住 `Alt` 临时绕过吸附，不会修改这些持久设置。

**贴图管理面板**：先点选列表项，按住 `Ctrl` 再点其他项可增减选择；按住 `Shift` 可选择连续项。“定位”将所选贴图带到前景并同步桌面临时选择；“显示/隐藏”和“关闭所选”作用于当前选择。建组前先多选成员，再执行“新建组”或“加入组”；选择组后点击组操作区下方的“批量设置”，可统一设定透明度、显示状态、锁定、置顶、描边、阴影、点击穿透，也可重置成员大小或旋转角度。各属性使用“保持各成员当前值/统一开启/统一关闭”选项，避免混合状态时误改未调整的属性。“显隐组”快捷按钮仍可将混合显隐状态统一切换为显示。“删除组”只解除分组关系，不关闭窗口或删除源图片；“关闭组”才关闭组内贴图。移动固定组时先选组，再输入水平/垂直偏移并执行“移动组”。

每张贴图都是独立窗口。左键拖动移动；滚轮缩放（倍率限制 0.1–10），缩放时短暂显示当前百分比；方向键或 WASD 每次移动 1 像素；Esc 关闭当前贴图。贴图默认描边、阴影和选中光晕可在“设置 > 贴图 > 贴图外观”配置，页面预览会即时反映描边、阴影、光晕开关及光晕强度。描边和阴影设置影响新建贴图的默认值；光晕强度范围为 0–100%，默认 30%。

拖动贴图时会自动吸附对齐：靠近屏幕工作区、其他可见应用窗口或另一张可见贴图的边缘（默认 8 逻辑像素内）即贴合，贴图目标优先于普通窗口；吸附瞬间沿图像外沿显示一圈青色虚线。按住 `Alt` 拖动可临时取消吸附，方便像素级摆放。贴到应用窗口后默认跟随该窗口移动；贴到另一张贴图后默认也会跟随，位置按吸附时的相对偏移同步。贴图间关系保持单向并拒绝形成循环；目标贴图关闭后自动解除跟随。目标窗口最小化或隐藏时暂停跟随但保留吸附关系，恢复后继续跟随，只有窗口真正关闭才自动解除吸附。可在“设置 > 贴图”关闭贴图间跟随，也可在右键菜单按目标分别开关跟随或直接解除吸附。

右键菜单提供锁定/解锁、重置大小、复制图像、从文件打开替换此贴图、从文件打开新贴图、描边开关、阴影开关、置顶开关、跟随吸附目标/取消跟随、解除吸附、关闭当前贴图、透明度滑块及点击穿透。替换会保留当前窗口的位置与缩放；取消文件选择不会更改贴图。锁定后不能拖动、缩放或用方向键移动。点击穿透后无法从贴图本身打开右键菜单，使用 `Ctrl+Shift+T` 恢复贴图交互。描边/阴影右键菜单只控制当前贴图是否显示，颜色、宽度和强度由全局设置控制；选中光晕开关和强度由“贴图外观”设置控制。

**右键菜单逐项操作**：

- **重置大小**把当前贴图缩放倍率恢复为 100%，不改变位置、图片源或其他贴图；旋转过的贴图按旋转后的图像边界计算大小。
- **复制图像**复制源图像像素，不会把窗口边框、阴影、棋盘背景或屏幕缩放效果写进剪贴板。
- **替换此贴图**只替换当前窗口内容并保留位置和倍率；取消文件选择不做更改。**从文件打开新贴图**则新建独立窗口。
- **置顶**只影响当前贴图；**锁定**禁止拖动、滚轮缩放和方向键移动，但仍可从菜单解锁。
- **跟随/取消跟随**只切换当前吸附目标的移动同步；**解除吸附**同时清除目标与跟随。目标隐藏时暂停，恢复后继续；目标关闭则解除。贴图跟随为单向关系，拒绝形成循环。
- **透明度滑块**即时调整当前贴图；**点击穿透**让鼠标操作落到后方窗口，之后用 `Ctrl+Shift+T` 恢复所有贴图交互。

贴图窗口在退出时保存屏幕位置、实际宽高、相对原图的缩放倍率、旋转、透明度、锁定/置顶/点击穿透状态、分组和有效吸附关系；下次启动自动恢复。拖动和缩放后的状态经过短暂防抖写入，退出时再强制刷新。源文件删除或不可读取时跳过对应贴图，不恢复空白窗口。

关闭组会在操作完成前同步保存贴图会话；“删除组”或取消归组仍只清除分组关系，不会关闭成员贴图。

### 通知

Windows 截图提示优先使用带缩略图的原生图片 Toast；无法导入或发送时回退到应用内非激活预览，其他平台使用应用内预览。截图通知点击可定位已保存文件；贴图和一般状态使用系统托盘文字通知，点击贴图通知可打开贴图管理窗口。截图进入编辑器时，初始保存并入现有截图提示；后续用户主动保存仍单独显示保存结果。

截图图片提示在 Windows 上优先使用 Win11 原生图片 Toast，缓存本地 PNG 作为 hero 图片；点击 Toast 会定位已经保存的文件。Toast 线程不会阻塞 Qt 界面，点击事件切回 Qt 主线程读取最新文件目标，因此截图刚完成、初始保存稍后才结束时也能使用正确路径。无法导入/发送原生 Toast 时回退到应用内图片预览；非 Windows 平台始终使用应用内预览。贴图和一般状态继续使用托盘文字提示。通知是否出现仍受“设置 > 常规 > 通知总开关”和对应分类开关控制。

## 技术指南

应用入口为 `main.py`。`core/` 负责配置、路径、图像与应用生命周期；`screenshot/` 管理截图遮罩、选区及原地编辑；`editor/` 提供共享画布、工具栏和独立编辑窗口；`sticker/` 管理置顶贴图、历史导航与会话恢复；`ui/` 放置托盘、设置、通知等界面；`hotkey/` 和 `logger/` 分别封装全局快捷键与日志。

改动截图流程时，同时检查原地编辑、独立窗口、多选区和多显示器路径；改动贴图状态时检查创建、关闭、重启恢复及旧 session 兼容。高频移动、缩放和定时保存只记录状态变化或限频错误，不逐次输出日志；等级和敏感数据要求见项目根目录 `AGENTS.md`。

## 测试与打包

在项目目录使用 `pytest tests/test_core.py` 运行核心测试；聚焦改动时可追加 `-k "关键词"`。测试使用 Qt offscreen 后端，不验证 Windows 桌面原生 Toast、全局热键权限、真实显示器 DPI 和窗口管理器行为，这些仍需在目标 Windows 环境手动验收。语法检查可运行 `python -m compileall -q .`。

`start up.bat` 用于创建/修复 `.venv` 并启动源码程序。仓库未包含 PyInstaller spec 或独立发布流水线；发布包构建需由维护者在目标环境配置并验证，不能仅以源码测试通过代替打包验收。

## 已知限制

- 全局快捷键依赖 Windows 键盘钩子；前后台进程权限等级不一致时，热键可能无法生效。先检查“设置 > 快捷键”绑定和总开关，再让程序与目标窗口以相同权限运行。
- 点击穿透会让鼠标事件落到后方窗口，贴图本身无法接收右键；使用 `Ctrl+Shift+T` 恢复贴图交互。
- 多显示器混合 DPI、跨屏选区、原生 Toast 点击回调和系统窗口吸附受 Windows 桌面状态影响，自动化离屏测试不能覆盖所有驱动、通知设置及权限组合。
- 贴图会话引用自动保存目录中的图像；若源文件被移动、删除或无法读取，重启时会跳过该贴图，不会创建空白窗口。
