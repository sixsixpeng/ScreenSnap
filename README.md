# ScreenSnap

ScreenSnap 是一个基于 Python 与 PySide6 的 Windows 优先截图与贴图工具。程序启动后常驻系统托盘，不保留主窗口，几乎所有操作都通过托盘菜单、全局热键或截图遮罩完成，不打断当前工作。

它把"截图 → 标注 → 变换 → 输出 → 贴图"串成一条顺手的流水线：截图后既能在选区原位做轻量编辑（原地编辑），也能打开独立编辑器进行矢量标注与图像变换；最终可保存为多种格式，或把结果贴成桌面置顶窗口长期参照。核心能力包括：

- **截图**：混合 DPI 多显示器、虚拟桌面坐标与负坐标显示器均支持；自由矩形选区、多选区、固定尺寸、上次位置重截、整屏/当前显示器一键截取，可选延迟与鼠标光标合成。
- **原地编辑**：单屏单选区直接在选区位置打开两排图标工具栏，就地标注、变换与保存，不弹出独立窗口，最大化保留截图上下文并减少遮挡。
- **独立编辑**：多选区、跨屏或关闭原地编辑时使用，提供完整画布导航、矢量标注、图像变换与输出效果。
- **贴图**：把截图、文件、文字、颜色作为独立置顶窗口贴在桌面，支持锁定、置顶、缩放、透明度、吸附与跟随，并用管理面板做分组与批量操作。
- **自动化与集成**：全局热键、剪贴板多类型贴图、基于 Windows UI Automation 的窗口/控件识别、Win11 原生图片 Toast 通知。

**怎么开始**：按"快速开始"用 `start up.bat` 或手动建 `.venv` 并安装 [requirements.txt](requirements.txt) 后启动；日常截图用双击托盘图标或 `F1`，选区确认后按"截图确认后"设置进入编辑或直接保存；配置在右键托盘图标 → 设置中修改，十类设置页即时生效并持久化。

本文同时作为**用户操作手册**和**开发维护指南**。界面、快捷键、配置项或工作流发生变化时，应在同一改动中更新相应章节和测试说明。

## 快速开始

需要 Windows 和 Python 3.10 或更高版本（安装时勾选加入 PATH）。在项目目录运行
[`start up.bat`](start%20up.bat)：脚本检查系统 Python；若缺失则中文提示并等待按键退出。
若 `.venv\Scripts\pythonw.exe` 缺失，脚本会删除旧 `.venv` 并重建；随后激活虚拟环境、
安装 [requirements.txt](requirements.txt)，最后以 `pythonw main.py` 启动托盘程序。
首次运行需要能访问 pip 包源；安装失败会显示原因并等待按键，不启动程序。

也可以手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

程序启动后会显示托盘就绪提示。右键托盘图标可快速截图、编辑剪贴板图片、打开图片、进入设置或退出；双击托盘图标开始自由选区截图。

依赖清单见 [requirements.txt](requirements.txt)。全局热键依赖 `keyboard`；Windows 的窗口边缘吸附还使用 `pywin32`。

## 操作手册

### 截图

- `F1` 开始自由选区。可在一个遮罩中创建多个矩形；按 Enter 或左键双击执行"截图确认后"设置（默认进入编辑器）。选择"仅保存，不打开编辑器"可改为直存。右键双击和快速保存按键 `S` 始终直接保存；未选区时按 Esc 退出截图。若启动后第一次截图按 Esc 没有反应，是 Windows 不允许后台进程抢占前台、遮罩尚未拿到键盘焦点所致；程序会先尝试把遮罩真正切到前台（`core/window_focus.py`），仍失败时临时挂一个全局 Esc 钩子保证能退出，点击一下遮罩后即恢复正常，后续截图不再出现。
- `Ctrl+Shift+F1` 选择整个虚拟桌面；`Ctrl+F1` 选择鼠标所在的当前显示器。
- `Ctrl+Shift+F2` 重用上次选区的位置和大小，在新画面中重新截图。显示器布局变化后若选区已不在桌面范围内，程序会提示。
- `F`（可在"设置 > 截图 > 截图快捷操作"改键）打开固定尺寸选区输入框；输入宽高后，在当前鼠标位置建立选区。
- 选区存在时按 `S` 可快速直接保存；可在"设置 > 截图 > 截图快捷操作"修改。快速保存沿用输出外观、格式、目录、剪贴板和保存通知配置。
- 默认进入编辑：开启"原地编辑"时，单屏单选区在截图位置打开原地编辑；多个选区、跨屏选区或关闭"原地编辑"时打开独立编辑器。选区阶段按 `E`（可改键）即可打开独立编辑器；原地编辑工具栏里也保留"窗口编辑"按钮。
- 注意：左键双击不是快速保存键，它跟随"截图确认后"设置；右键双击和 `S`（可在常规页改键）是无条件直存操作。
- 快速贴图默认按键为 `Space`，功能默认开启；可在"设置 > 截图 > 截图快捷操作"修改按键，选区存在时按下会直接打开贴图，不进入编辑。
- 选区阶段的四个功能（**自定义尺寸 / 重新截图 / 窗口编辑 / 仅复制**）不再用遮罩上的按钮，改为四个**可配置单键**（默认 `F` / `R` / `E` / `Y`，在"设置 > 截图 > 截图快捷操作"改键）：自定义尺寸按指定宽高在当前鼠标位置建立选区（宽高默认填整屏像素）；重新截图放弃当前这一屏已冻结的画面、回到同一显示器重新框选（不保留当前标注）；窗口编辑把选区送进独立编辑器；仅复制把整屏（有选区时取选区）写入剪贴板并关闭遮罩，不落盘、不进编辑器。这四个键只在**有选区且未进入编辑**时生效；提示条会按当前设置实时显示「`F 自定义尺寸 | R 重新截图 | E 窗口编辑 | Y 仅复制`」，改键后提示立刻跟着变（提示条每一项都能在「设置 > 截图 > 操作提示」里单独开关与排序）。
- 拖动选区内部可移动；拖动四角或边缘中点可调整大小。选区接近屏幕或可见窗口边缘时会吸附。选中选区后使用方向键或 WASD 可微调位置。
- `Tab` / `Shift+Tab` 把选区切到鼠标下的窗口、分组容器或控件（由外到内逐层进入）；开启"自动选中窗口"后，开始截图即直接选中鼠标下的窗口。浏览器、Electron 等自绘界面可优先通过 UIA 识别已暴露的无障碍节点；未暴露节点时回退到顶层窗口句柄。
- 开启"移动鼠标自动识别"后，移动鼠标会以蓝色半透明块实时高亮下方的窗口或控件（取最内层），**左键单击即选中该区域**，按住拖动仍然手绘选区；想选外层窗口或父容器时按 `Tab` 逐层切换。高亮颜色和填充不透明度，以及识别刷新间隔，都可在"设置 > 截图 > 窗口与控件识别"中调整；默认使用 `#168cff` 蓝色和 35% 填充不透明度，边框保持实色。该页还提供候选框风格预设（海湾青/冰蓝/琥珀/玫瑰）、候选框显示方式（`reveal` 透出原图，仅描边与尺寸标签；`fill` 半透明填充）、候选框边线颜色与宽度，以及随高亮显示的控件尺寸标签底色、文字颜色与字号，均可单独配置。默认走 `reveal` 透出原图，此时候选框**没有填充**，因此"候选框填充颜色"和"候选框填充不透明度"不参与绘制，两个控件都会置灰；切到"半透明颜色填充"后二者才生效，选择任一风格预设会自动切到该模式。
- "设置 > 截图 > 窗口与控件识别"分为「基础识别」「候选框外观」「无障碍识别与精度」三组：基础识别含识别总开关、自动选中、悬停高亮（含预览）；候选框外观含显示方式、风格、填充/边线/文字/标签颜色与不透明度及字号；无障碍识别与精度含 UIA 优先级、悬停刷新间隔、识别层级与 UIA 诊断。默认开启 UIA：识别会先用 Windows 无障碍树读取浏览器、Electron、Qt/WPF 等自绘界面内部的按钮、标签和编辑框，需要安装 `uiautomation`（`python -m pip install uiautomation`）；未安装或查询失败时自动退回窗口句柄识别。UIA 命中后最多继续向下查找 24 层，并优先沿覆盖鼠标点的最小子控件下钻；"识别层级"控制的是 Tab 可切换的祖先层数，不控制这段向下搜索。仍无法读取未暴露给 Windows 无障碍树的自绘元素。本程序的截图遮罩与贴图会穿透识别，同进程普通窗口仍可作为目标。
- "设置 > 截图 > 遮罩与选区"可选择清透蓝、薄荷绿、奶油黄、樱花粉、淡紫等遮罩色预设，也可自定义颜色和不透明度；默认黑色 `#000000`、60% 不透明度。旧版深色/浅色选择会分别迁移为黑色/白色遮罩。
- "设置 > 截图 > 截图时机"里可设置**截图延迟**（0–5000 毫秒）：按下全局截图热键后先等待再抓画面，用于避开快捷键冲突造成的界面变化，或等待菜单、动画、网页渲染完成。托盘菜单发起的截图会自动再追加 150 毫秒等待菜单关闭。
- 选区确认前可按 `C` 进入**取色模式**：取色态下 `Alt`/`Ctrl` + 左键在画面上取样会把十六进制色值复制到剪贴板并设为当前标注颜色；跟随放大镜的提示条实时显示坐标、色值与操作（`Alt/Ctrl+左键` 取样复制、`C`/`Esc` 退出）。用 Alt/Ctrl 修饰取样，避免与左键框选 / UIA 自动识别选择冲突。取色依赖放大镜与十字线，「设置 > 截图 > 取色」还提供放大镜像素网格开关与网格颜色。
- 开启「标尺」后，选区四边会绘制像素刻度（底部/左侧带数值），辅助定位与测量；刻度与数值颜色可在「设置 > 截图 > 取色」配置（标尺默认关闭）。
- 「截图确认后」新增**仅复制到剪贴板**（`copy`）选项：确认后把选区图片写入系统剪贴板并关闭遮罩，不落盘也不进编辑器；选区阶段按 `Y`（可改键）亦可随时触发。
- 选区包含**本程序自身的窗口**（设置窗口、编辑器、通知缩略图、贴图、贴图管理、回收站、外观弹层、弹出菜单等）时，默认**不提示**：截图就是抓屏，程序不会替你关闭这些窗口。需要提醒时可在"设置 > 截图 > 操作提示 > 采集自检警示"打开总开关，并逐类勾选要参与提示的窗口类型；打开后提示条会在最前面附加一句暖色警示（如"⚠ 选区内有贴图，移开后重截"）。系统通知不参与提示。

- 多显示器截图使用虚拟桌面坐标，支持显示器负坐标；显示器之间的间隙也处于虚拟桌面矩形内。
- 截图提示显示首个选区的缩略图和选区总数，约 4 秒后关闭。提示、尺寸文字、十字线和放大镜不会写入截图。
- 单选区且完整位于同一显示器内时，默认进入**原地编辑**：不会打开新编辑窗口，而是在选区上直接显示编辑画布和紧凑图标工具栏。工具栏为两排 24px 图标（约为 320×51），只有内容本身决定宽高，尽量少遮挡截图区域；按钮名称与说明仍通过多行 tooltip 展示。多选区或跨屏选区会自动回退到独立编辑器窗口，避免多画布和跨屏 DPI 坐标冲突。
- **工具栏遮挡内容时可拖开或临时隐藏**：整条工具栏（左端「≡」抓手与按钮之间的空白处都算）用"可移动"光标提示，按住任意一处即可整体拖动，松手时靠近自动摆位候选点（选区外四角等）会吸附，双击空白处恢复自动位置；拖动只在**本次编辑**内有效，不持久化。按 `` ` ``（可在"设置 > 截图 > 截图快捷操作"改键）临时隐藏/恢复工具栏——隐藏只由快捷键触发，没有按钮，跟随放大镜的提示条会显示当前键位（编辑中显示「拖动边缘/空白处 移动工具栏 | `` ` `` 隐藏工具栏」，隐藏后显示「`` ` `` 显示工具栏」；两项都可在「设置 > 截图 > 操作提示」里关闭）。
- 进入原地编辑后不能继续新增选区，但可以拖动已有选区的角点或边中点调整大小；调整时会隐藏旧编辑层，释放鼠标后按新区域重新裁剪并重建编辑画布。调整选区会清空该区域已有标注，避免标注坐标与新截图区域错位。
- 原地编辑会立即保存一次初始截图；点击保存或双击空白会覆盖同一个文件并退出；放弃会关闭编辑层但保留初始截图文件。
- 未选区、调整选区和原地编辑时均可显示放大镜；原地编辑按 Esc 直接退出本次截图，不返回选区状态。"显示鼠标"开关只在本次截图存在带/不带鼠标两版时可用。
- 原地编辑不提供裁剪工具；需要裁剪图片时可在独立编辑窗口中使用。取色后紧凑工具栏的颜色按钮仍只显示色块。

遮罩深浅、锚点样式、十字线颜色和宽度、放大镜、光标捕获及通知均可在设置中调整。遮罩不透明度 0% 表示不遮盖选区外区域，100% 表示完全遮盖。

### 编辑器

#### 标注工具

标注工具包括选择、画笔、记号笔、文字、箭头、矩形、椭圆、橡皮擦、马赛克、取色、序号和裁剪。编辑器默认大小为 1200×760。各工具的颜色和样式在"设置 > 编辑器"的工具专属分组中配置；画笔、矩形、椭圆和橡皮擦分别提供独立参数和预览。橡皮擦直径可设为 10–100，默认 30；编辑器工具栏切换到橡皮擦时使用相同范围。擦除按路径非破坏地生效，**被擦过的标注仍可选中、编辑与删除**；擦除内容本身可单独删除（在被擦区域右键 →「删除此处擦除 / 删除最近一次擦除 / 清除全部擦除」），右键菜单还能逐笔勾选「此处同时擦除原图」。工具栏"更多设置"显示当前工具的颜色与预览；吸管取色后写入进入吸管前最近使用的可调色工具独立颜色，并复制色值到剪贴板。取色工具显示滴管光标。"显示鼠标"位于标注区域。单选区原地编辑使用紧凑图标工具栏：两排 24px 图标（图标 16px），组标题隐藏、内边距与行列间距收紧，工具栏宽度不再设下限；按钮名称与说明通过多行 tooltip 展示。当前选中的标注工具按钮使用统一的灰黑色底、边框和文字对比，窗口编辑与单图快速编辑保持一致。

"更多设置"随当前工具显示对应参数。选择工具下，单选标注后显示该类型的颜色、线宽、专属参数和预览（包含圆角矩形）；无单选、多选或不可识别类型时禁用专属设置，不回退到无关箭头参数。双击删除非文字标注后清空已删除项的设置，重新单选其他标注即可调整对应参数；文字仍双击编辑。窗口编辑与原地编辑均在弹出菜单前核对当前选区。单区原地编辑工具栏保留"自定义尺寸"和"重新截图"，因为它仍负责当前截图选区；"窗口编辑"打开的独立窗口只负责编辑，不显示这两个截图控制按钮。**自定义尺寸**按指定宽高重设选区，中心位置保持不变，并立即按新尺寸重新载入该区域画面；**重新截图**放弃当前画面并重新进入截图，可等画面变化后再框选同一区域。两者的 tooltip 与按钮名不再重复同一句话。

**跟随放大镜的提示条**：不再贴屏幕顶部，而是画在放大镜框的**下方**（下方放不下就画上方），因此不需要"鼠标移入隐藏、移出恢复"那套避让；放大镜关闭或弹出菜单/模态框遮挡时，仍按同一套避让规则算出框，提示继续跟着光标显示。提示条本身是**独立于截图内容的浮层**（与放大镜同级，压在选区与原地编辑画布之上），因此光标移进选区、进入原地编辑后都不会被内容盖住。内容是一组**可独立开关、可排序**的提示项（「设置 > 截图 > 操作提示」里勾选与拖动），默认顺序为「坐标与尺寸 ｜ 拖动移动 ｜ 缩放 ｜ 框选 ｜ 编辑 ｜ 微调 ｜ 取消 ｜ 保存 ｜ 贴图 ｜ 取色 ｜ 自定义尺寸 ｜ 重新截图 ｜ 窗口编辑 ｜ 仅复制 ｜ 移动工具栏 ｜ 隐藏工具栏」，当前阶段不适用的项会自动省略（例如还没框选时不会提示"拖动移动"）。该分组顶部还有「显示快捷键提示」总开关，关掉后整条不显示（放大镜、十字线等其它定位辅助不受影响），并提供一个**实时预览**：勾选、排序、改键后预览立刻显示最新键位与顺序。「每行提示数」控制一行最多放几个提示（默认 2，0 表示只按宽度自动换行），配合顺序列表可以把重要的键位固定在第一行；顺序既可按条目拖动，也可选中后用「上移 / 下移」按钮。提示条与**放大镜的边缘对齐**（放大镜在光标右侧就对齐左边，翻到光标左侧就对齐右边），再向光标外侧挪 10px；**文字对齐跟随同一条贴边规则**：对齐放大镜左边时左对齐，对齐右边时右对齐。**贴屏幕下沿时提示条跟放大镜一起翻到上方**，两条始终在光标同一侧，不会反过来盖住光标中心。每行放不下的项会整体挪到下一行，**不截断单个提示项**；提示条最大宽度 420px，高度受所在区域限制（屏幕很小时不会铺满画面）；全部提示项都关掉时整条不画。悬停控件时的尺寸徽标会避开提示条，避免叠在一起。

**吸管取色的具体反馈位置**：先选择矩形、箭头、文字等有颜色参数的工具，再选择"取色"并在图片上左键取样。取样色会写回进入吸管前最近使用的可调色工具，而不是固定写入画笔：例如从矩形切到吸管，取样后矩形颜色改变，画笔颜色保持原值。颜色会显示在工具栏"当前工具颜色"色块和"更多设置"的颜色行，并以 `#RRGGBB` 复制到系统剪贴板；切回原工具即可继续使用该颜色。紧凑原地编辑工具栏只显示色块，详细颜色设置仍在"更多设置"里。

**序号标注**：工具栏「序号」工具在图片上单击放置序号标记，号码自动递增，便于逐步标注步骤。形状可选圆/方/三角/菱形/五边形/六边形/星形/心形/箭头/对话气泡/云/十字/水滴；可分别设置填充色、文字色、字号与起始值，或用预设组合（自定义/红圆/蓝方/绿星/琥珀菱形/紫五边形/青六边形/红心/蓝箭头）一键套用形状与配色。「设置 > 编辑器 > 序号标注」与编辑器/原地编辑「更多设置」均可调整并实时预览。

#### 浏览、缩放和变换

- 右键或中键拖动画布，或按住空格拖动，可平移画布；右键单击已有标注则打开标注菜单。
- 鼠标滚轮默认上下滚动；按住 Ctrl 或 Alt 滚轮改为横向移动。纵向、横向滚动步长均已调小；滚轮不缩放画布，也不缩放选中标注。
- 用选择工具拖动选中标注的边框或缩放手柄时，原标注内容保持可见并随拖动实时缩放，不会被白色选择框遮住；独立窗口编辑和单区原地编辑行为一致。
- 画布显示缩放通过编辑器下方的滑块或百分比输入控制，范围为 1%–800%。显示缩放不改变导出图片分辨率。
- 图像旋转区域的第一个按钮是"重置角度"：应用任意角度旋转后可恢复旋转前状态；编辑图像或标注后该入口会禁用。左右旋转 90°、旋转 180°、水平/垂直翻转及任意角度旋转也在该区域。
- 任意角度旋转支持旋钮预览和数字精确输入；取消恢复原状态，确认后记录为一次可撤销操作。旋转和翻转会同步变换现有标注。
- 撤销、重做和重置操作位于编辑区域。重置用于恢复原始截图状态。

#### 输出

最终图片外观设置位于"设置 > 保存与输出"，包括透明圆角、半径、边框和阴影。边框覆盖图像最外沿，不留原图窄边；圆角与边框边缘使用超采样抗锯齿。编辑器工具栏"输出"组中的"外观"按钮也可打开同一套控制和最终预览；从任一入口修改都会保存并同步到设置页和已打开的编辑器。

点击"外观"打开预览面板，再点一次同一按钮即可关闭；按 Esc 或点击面板外也会关闭。圆角、边框和阴影分别由面板中的开关控制，数值控件会即时更新预览并同步保存。单图编辑和截图原地编辑使用同一套行为。

快速贴图默认按键为 `Space`，功能默认**开启**。可在"设置 > 截图 > 截图快捷操作"关闭或改成其他按键组合；选区存在时按下会直接打开贴图，不进入编辑。

圆角选区遮罩、编辑画布预览和标注合成均使用抗锯齿；最终保存、复制和贴图输出使用超采样圆角蒙版。源截图保持完整，编辑时仍可关闭圆角或调整半径。

- **保存**：保存 PNG 到手动保存目录，按保存设置中两个独立开关复制图片和/或文件路径到剪贴板，然后退出编辑器；默认复制图片、不复制路径。
- **贴图**：自动保存当前合成图，将其作为独立置顶窗口打开，然后关闭编辑器。
- **放弃**或 Esc：关闭编辑器，不保存当前编辑结果。
- 双击空白画布执行保存操作。保存成功提示可显示最终图片缩略图。

原地编辑中的输出按钮含义更直接：**贴图** 会保存当前合成图、创建贴图并退出截图编辑；**保存** 会覆盖当前初始文件，按相同剪贴板开关复制内容并退出；双击空白画布执行同样的保存动作。初始自动保存不修改剪贴板，显式点击"复制图片"始终复制图片；**放弃** 会退出但不覆盖修改。选区尺寸调整不会反复触发自动保存；单张原地编辑不显示"关闭全部"按钮。

单张截图默认可能进入原地编辑，多张选区或跨显示器选区使用独立窗口。两种编辑器里的"贴图"都是独立于"保存"的动作：会先按自动保存目录保存当前合成图，再创建一张置顶贴图，最后关闭编辑界面；仅点"保存"不会创建贴图。若要从文件开始制作贴图，可从托盘选择"从文件打开新贴图"；若要编辑已有贴图，在该贴图右键选择"编辑"，修改后点"贴图"创建新贴图，原贴图不会被覆盖。原地编辑的"窗口编辑"按钮是将同一选区转到独立窗口继续编辑，不是贴图按钮，也不会创建第二张截图。

编辑器的滚轮和按键行为也会显示在画布下方的操作提示中；支持当前快捷键的按钮和菜单项会显示绑定提示。

### 贴图窗口

贴图是独立的置顶窗口，内容可以来自截图、图片文件、文字、颜色或剪贴板历史。常见入口：编辑器点"贴图"（先按自动保存目录落盘，再贴出并关闭编辑界面）；截图遮罩中选区存在时按 `Space` 快速贴图；托盘"从文件打开新贴图"或 `Ctrl+Alt+N` 选图新建；`F3` 按时间顺序贴出尚未显示过的历史图片；`Ctrl+Alt+Left` / `Ctrl+Alt+Right` 在历史贴图窗口里换图；`Ctrl+F3` 轮播剪贴板历史，其中文字、颜色、文件分别渲染为文字卡片、色块卡片和文件卡片（外观在"设置 > 剪贴板贴图"调整）。

按 `F3` 的"尚未贴出"列表与 `Ctrl+Alt+Left` / `Ctrl+Alt+Right` 的图片历史是两套导航：F3 逐次创建尚未显示过的旧图片；上一张/下一张在一个可复用的历史贴图窗口里换图。到达历史边界时不会创建空贴图；关闭 F3 创建的贴图后，该文件可再次由 F3 打开。历史源于自动保存目录，移动或删除目录内文件会影响可打开条目。

`Ctrl+F3`（贴剪贴板内容）不是只贴当前剪贴板，而是在 ScreenSnap 已记录的**剪贴板历史**中逐个轮播：每当复制图片、文件、HTML、文字或颜色都会被记入历史，连续按 `Ctrl+F3` 依次把上一条历史内容作为贴图贴出；历史按 `history_limit` 上限保存并写入 `clipboard_history.json`，可跨重启保留。若当前剪贴板内容尚未入史，首次按下会先贴出当前剪贴板。

贴图窗口在退出时保存屏幕位置、实际宽高、相对原图的缩放倍率、旋转、透明度、锁定/置顶/点击穿透状态、分组和有效吸附关系；下次启动自动恢复。拖动和缩放后的状态经过短暂防抖写入，退出时再强制刷新。源文件删除或不可读取时跳过对应贴图，不恢复空白窗口。

**右键菜单逐项操作**：

- **重置大小**把当前贴图缩放倍率恢复为 100%，不改变位置、图片源或其他贴图；旋转过的贴图按旋转后的图像边界计算大小。
- **复制图像**复制源图像像素，不会把窗口边框、阴影、棋盘背景或屏幕缩放效果写进剪贴板。
- **替换此贴图**只替换当前窗口内容并保留位置和倍率；取消文件选择不做更改。**从文件打开新贴图**则新建独立窗口。
- **置顶**只影响当前贴图；**锁定**禁止拖动、滚轮缩放和方向键移动，但仍可从菜单解锁。
- **跟随/取消跟随**只切换当前吸附目标的移动同步；**解除吸附**同时清除目标与跟随。目标隐藏时暂停，恢复后继续；目标关闭则解除。贴图跟随为单向关系，拒绝形成循环。
- **透明度滑块**即时调整当前贴图；**点击穿透**让鼠标操作落到后方窗口，之后用 `Ctrl+Shift+T` 恢复所有贴图交互。
- **旋转**子菜单：逆时针/顺时针 90° 与恢复原方向。
- **背景模式**子菜单：逐张切换 `transparent` / `pseudo` / 暗色棋盘 / 亮色棋盘。
- **分组**子菜单：归入已有组或移出到未分组。
- **打开原文件**用系统关联程序打开贴图源文件。
- **复制文字 / 复制富文本 / 复制颜色值**：针对文字、富文本、颜色贴图把对应内容写回剪贴板。

关闭贴图默认进入**回收站**而非直接删除，降低误删风险：右键菜单「回收站」子菜单可逐项恢复已关闭的贴图，或一键清空回收站（空时显示占位项）。回收站上限在「设置 > 贴图 > 回收站」配置，超出时自动丢弃最早进入的项；关闭该开关则关闭贴图直接删除。也可用全局快捷键 `Ctrl+Alt+R` 或从托盘菜单「贴图回收站」打开回收站窗口。

每张贴图都是独立窗口。左键拖动移动；滚轮缩放（倍率限制 0.1–10），缩放时短暂显示当前百分比；方向键或 WASD 每次移动 1 像素；Esc 关闭当前贴图。贴图默认描边、阴影和选中光晕可在"设置 > 贴图 > 贴图外观"配置，页面预览会即时反映描边、阴影、光晕开关及光晕强度。描边和阴影设置影响新建贴图的默认值；光晕强度范围为 0–100%，默认 30%。描边**跟随贴图圆角**：输出圆角开启时（截图类贴图）描边沿圆弧走，直角贴图保持直角；描边整体画在图像内侧，因此透明背景模式下也不会被输入遮罩裁掉。阴影为贴图**外侧的投影**（偏移形状减去贴图形状绘制，只落在图片之外），因此不会压暗贴图主体；选中光晕同样跟随圆角（原来阴影是方形、光晕固定 5px 圆角且画在 padding 上被遮罩裁掉），吸附提示虚线也移到图像内侧并跟随圆角，三种背景模式下都完整可见。

贴图透明区域显示为四种背景之一，在"设置 > 贴图 > 透明图像背景"选择：`transparent` 完全透明（鼠标需落在内容像素上才能拖动）、`pseudo` 伪透明（整张含透明像素均可拖动，便于抓取空白处）、`dark_checker` / `light_checker` 暗色/亮色棋盘（直观预览透明区域）。单张贴图也可在右键菜单"背景模式"子菜单中单独切换，不影响全局默认。

拖动贴图时会自动吸附对齐：靠近屏幕工作区、其他可见应用窗口或另一张可见贴图的边缘（默认 8 逻辑像素内）即贴合，贴图目标优先于普通窗口；吸附瞬间沿图像外沿显示一圈青色虚线。按住 `Alt` 拖动可临时取消吸附，方便像素级摆放。贴到应用窗口后默认跟随该窗口移动；贴到另一张贴图后默认也会跟随，位置按吸附时的相对偏移同步。贴图间关系保持单向并拒绝形成循环；目标贴图关闭后自动解除跟随。目标窗口最小化或隐藏时暂停跟随但保留吸附关系，恢复后继续跟随，只有窗口真正关闭才自动解除吸附。可在"设置 > 贴图"关闭贴图间跟随，也可在右键菜单按目标分别开关跟随或直接解除吸附。

右键菜单提供锁定/解锁、重置大小、复制图像、从文件打开替换此贴图、从文件打开新贴图、描边开关、阴影开关、置顶开关、跟随吸附目标/取消跟随、解除吸附、关闭当前贴图、透明度滑块及点击穿透。替换会保留当前窗口的位置与缩放；取消文件选择不会更改贴图。锁定后不能拖动、缩放或用方向键移动。点击穿透后无法从贴图本身打开右键菜单，使用 `Ctrl+Shift+T` 恢复贴图交互。描边/阴影右键菜单只控制当前贴图是否显示，颜色、宽度和强度由全局设置控制；选中光晕开关和强度由"贴图外观"设置控制。

**贴图管理面板**（`Ctrl+Alt+P`，也可从托盘菜单打开）：先点选列表项，按住 `Ctrl` 再点其他项可增减选择；按住 `Shift` 可选择连续项。"定位"将所选贴图带到前景并同步桌面临时选择；"显示/隐藏"和"关闭所选"作用于当前选择。面板还提供"从文件添加"把所选文件直接加入当前组，以及"全部隐藏/显示"一键切换所有贴图的显隐。建组前先多选成员，再执行"新建组"或"加入组"；选择组后点击组操作区下方的"批量设置"，可统一设定透明度、显示状态、锁定、置顶、描边、阴影、点击穿透，也可重置成员大小或旋转角度。各属性使用"保持各成员当前值/统一开启/统一关闭"选项，避免混合状态时误改未调整的属性；批量修改在控件变化时立即生效，无需点应用，关闭对话框请用标题栏按钮或 Esc。"显隐组"快捷按钮仍可将混合显隐状态统一切换为显示。"删除组"只解除分组关系，不关闭窗口或删除源图片；"关闭组"才关闭组内贴图，并在操作完成前同步保存会话。移动固定组时先选组，再输入水平/垂直偏移并执行"移动组"。旋转可单选 -90°、180°、90° 预设，也可输入 -3600°至 3600°的整数自定义角度，输入完成后应用一次。

截图图片提示在 Windows 上优先使用 Win11 原生图片 Toast，缓存本地 PNG 作为 hero 图片；点击 Toast 会定位已经保存的文件。Toast 线程不会阻塞 Qt 界面，点击事件切回 Qt 主线程读取最新文件目标，因此截图刚完成、初始保存稍后才结束时也能使用正确路径。无法导入/发送原生 Toast 时回退到应用内图片预览；非 Windows 平台始终使用应用内预览。「仅复制到剪贴板」等复制类反馈为保证复制内容可见，一律使用应用内本地缩略图预览，不依赖 Win11 Toast 附带 hero 图（后者经常不显示缩略图）。贴图和一般状态继续使用托盘文字提示。通知是否出现仍受"设置 > 常规 > 通知总开关"和对应分类开关控制。

## 历史功能点与验收用例

本节把历史会话中提出的功能要求集中留档，作为用户手册之外的回归清单。当前行为以本 README 的操作手册和"已知限制"为准；已明确标为未支持的项目不视为完成。

### 功能详解

下面按使用场景说明各功能"能做什么、在哪里用、怎么用"。更细致的操作步骤见上方"操作手册"，具体配置键见"配置参数详解"。

**应用、配置和通知**：ScreenSnap 是 Windows 优先的 PySide6 托盘程序，启动后没有主窗口，右键托盘图标即可截图、编辑剪贴板图片、打开图片、新建贴图或进设置，双击托盘图标开始自由选区截图。首次启动生成默认配置，所有修改即时写入并持久化（合并 250ms 内的连续变更，关闭或退出时刷新最后一次）。全局快捷键在"设置 > 快捷键"录制、清除并检查冲突；通知按启动/截图/保存/贴图分类，可在"设置 > 常规 > 启动与通知"分别开关，Windows 11 优先原生图片 Toast，失败回退应用内预览。

**截图和选区**：面向混合 DPI 多显示器与虚拟桌面坐标（含负坐标）。`F1` 开始自由选区，`Ctrl+Shift+F1` 选整屏、`Ctrl+F1` 选当前显示器，`Ctrl+Shift+F2` 用上次位置重截，`F` 输入固定宽高，`S`/右键双击无条件直存，`Esc` 退出；选区阶段还有四个可配置单键：`F` 自定义尺寸、`R` 重新截图、`E` 窗口编辑、`Y` 仅复制（提示条按设置显示当前键位，每项可单独开关与排序）。选区可拖动、八方向调整并用方向键或 WASD 微调；遮罩色/不透明度、十字线、选区边框、放大镜（尺寸 100–320px 可调）均可独立设置。需要精准定位窗口或控件时，用 `Tab` 由外到内逐层切换、开启"移动鼠标自动识别"悬停高亮后左键即选中，浏览器/Electron 等自绘界面优先由 UIA 识别（需安装 `uiautomation`）。**采集自检**：抓屏前**不改变本程序的任何窗口**——截图就是截图，程序自身的贴图、设置窗口、编辑器、通知缩略图等都按屏幕现状采集（用户常拿程序自身当被测内容）；若选区内含本程序窗口（贴图、贴图管理/回收站、设置窗口、编辑器、按需弹出的「外观」弹层等），提示条会以暖色警示「⚠ 选区内有××，移开后重截」（警示固定在提示项最前，不受提示项开关影响）；抓屏瞬间仍开着的弹出菜单（如贴图右键菜单，抓屏后才关闭、已烤进冻结帧）也会并入同一句警示（系统通知不作提示——它是操作系统窗口，抓屏前关不掉也枚举不到，常驻提醒只会打扰用户）。窗口可用 `setProperty("screensnap_self_window", "提示名")` 自报，新增浮层不必改登记表。遮罩上绘制的提示条、按钮组、放大镜、标尺、十字线与控制点**只画在遮罩表面，不会进入裁切像素**，编辑器的导出也只渲染底图与标注（不含工具栏、滚动条与预览面板）。

**编辑画布与标注**：两种编辑器（原地/独立）共用标注画布、工具栏与输出效果。工具含选择、画笔、记号笔/荧光笔、文字、箭头、矩形、椭圆、橡皮擦、马赛克、取色与裁剪；各工具颜色、线型、线宽在"设置 > 编辑器"按工具分组配置并实时同步。文字支持字体/字号/文本框宽度与高度（可在"设置 > 编辑器 > 文字"或文字输入对话框调整；对话框预览**直接显示正在输入的文字**，并给出当前生效的宽度与高度，自动模式会标注按字体实测的值。宽度 0 表示按内容自动、按字体实测取较紧凑的宽度；高度 0 表示随内容自动增长，正数则固定高度并裁剪超出内容。新建文字取公共配置为默认，而**编辑已有文字时各项只作用于该标注、不回写公共配置**。选中文字标注后可拖动选框**左右边中点**调整宽度、**上下边中点**调整高度，**四角仍是整体缩放**），箭头支持箭头/空心箭头/虚线箭头、双向箭头/双向空心箭头/双向虚线箭头、箭杆矩形/空心箭杆/虚线箭杆、线段/虚线（单箭头改为三角形箭杆，双向保留矩形箭杆），马赛克支持效果与颗粒度，荧光笔为半透明宽线。选择工具可二次选中、移动与缩放已有标注；橡皮擦按路径非破坏地擦除，且**只影响其下方（更早绘制）的标注**——擦除后新画的标注位于擦除之上、不会被擦到，支持"标注→擦除→再标注→二次擦除"的多层叠加，被擦过的标注仍可正常选中、编辑与删除（命中测试会跳过擦除层），擦除内容也可单独删除而不必回退其后的标注——被擦区域右键可「删除此处擦除 / 删除最近一次擦除 / 清除全部擦除」，工具栏「层级」菜单也有后两项（按**每次拖动的笔迹**删除，不会因为笔迹合并进同一擦除层而一次清空全部）；「同时擦除原图」逐笔生效——开关只决定之后新擦除的默认值，已有擦除不受影响，也可在被擦处右键「此处同时擦除原图」单独调整；开启后擦过处的原图会变为**空白（透明）区域**。标注受图片边界约束。取色会把颜色写回进入吸管前最近使用的可调色工具，并复制到剪贴板。

**画布导航和图像变换**：编辑区初始居中，显示缩放由底部滑块或百分比输入控制（1%–800%，不改变导出分辨率）。滚轮默认垂直滚动，按住 `Ctrl`/`Alt` 改为横向；右键、中键或按住 `Space` 拖动平移。图像变换区提供左右 90°、180°、水平/垂直翻转与任意角度旋转（旋钮+精确输入，可重置），旋转/翻转会同步变换现有标注；撤销/重做与重置位于编辑区，裁剪边框样式与线宽可调。

**保存和输出**：输出外观（透明圆角/半径、边框、阴影）在"设置 > 保存与输出"与工具栏"输出 > 外观"共用并实时预览。格式支持 PNG/JPEG/WebP/BMP，并可设质量、透明底色、命名模板、自动/手动目录与按月/按日归档；保存时可分别开关复制图片与复制路径到剪贴板。保存、贴图、放弃、双击空白保存含义清晰区分：保存写盘并退出，贴图先落盘再开置顶窗口，放弃不写盘。截图预览通知保留图片内容，初次自动落盘不重复发成功通知。

**贴图与历史**：图片、文件、文字、颜色都能作为独立置顶窗口贴到桌面；可替换当前贴图、从文件新建贴图、`F3` 按时间顺序贴出尚未打开的历史图片、`Ctrl+Alt+Left/Right` 上一张/下一张、关闭后重新贴出、无效历史跳过（历史源于自动保存目录，跨重启保留）。贴图可锁定、置顶、滚轮缩放（0.1–10）、调透明度、吸附屏幕/普通窗口/其他贴图，并可单向跟随普通窗口或另一张贴图（目标关闭自动解除）。管理面板支持 Ctrl/Shift 多选、分组、整组显隐、关闭所选与关闭全部，Ctrl 点击后拖动可批量移动。

**界面与维护约定**：工具图标采用明确语义并配多行 tooltip；快捷键提示与当前绑定同步显示；设置控件与按钮需对齐、不重叠、自适应窗口宽度。项目采用模块化结构（`core`/`config`/`editor`/`screenshot`/`sticker`/`ui`/`hotkey`/`logger`），统一使用标准 `logging` 与静态绝对导入，并以 PyInstaller 打包；功能、配置、注释、README 与打包说明随行为变更同步维护。

### 手动验收用例

1. **首次启动与配置**：删除测试用配置后启动，确认生成默认设置和托盘提示；修改快捷键、标注默认参数及通知开关，重启后确认设置保留，冲突快捷键有反馈。
2. **多屏截图与退出**：在不同缩放比例/负坐标显示器上分别截图，检查光标版本、遮罩、十字线和放大镜；空选区按 Esc 关闭，拖动创建多个区域后分别调整和微调。
3. **选区操作**：按 `F`（或改键后的自定义尺寸键）用固定宽高创建区域，按 `R`/`E`/`Y` 验证重新截图、窗口编辑、仅复制三个快捷键；确认遮罩上**没有**四个功能按钮，提示条按设置显示当前键位（改键后立即跟随）。使用 Tab/悬停高亮选择窗口或控件，调整角点和边中点；确认提示、尺寸文字、十字线和放大镜没有写进输出图。在「设置 > 截图 > 操作提示」里取消勾选几项、用「上移 / 下移」调整顺序，确认**该页的预览**与截图时的提示条同步变化、改键后预览显示新键位；把「每行提示数」改成 1 或 3，确认提示条的换行随之变化（默认每行 2 个）；关掉「显示快捷键提示」确认整条消失、放大镜不受影响、再打开恢复。把光标移到屏幕最右侧再截图，确认提示条改为对齐放大镜右边、文字右对齐；把光标移到屏幕最下沿，确认放大镜与提示条**一起**翻到光标上方、不遮挡光标中心。把「放大镜尺寸」调到 280px，确认放大镜与提示条一起变大；关闭实时放大镜，确认提示条仍在光标附近显示。进入原地编辑并把光标移到选区内，确认提示条压在编辑画布之上（不再被内容盖住）。**采集自检**：先触发一次复制/保存让右下角出现通知缩略图，紧接着再截图，确认抓屏前**没有**任何本程序窗口被关闭或隐藏（缩略图、贴图、设置窗口都保持原样，随画面一起被采集），只有在选区覆盖它们时提示条才给出暖色警示；把一张贴图或设置窗口摆到选区里，确认顶部提示条变成暖色并出现「选区内有××，移开后重截」，移开后再截即恢复正常提示；打开工具栏「外观」弹层再截图，确认提示条点名「外观弹层」；开着贴图右键菜单截图，确认提示条点名弹出菜单（该菜单本身会留在冻结画面里，这是既有取舍）；另确认**不再**因刚发过系统通知而额外提示。
4. **编辑器职责**：单区启用原地编辑，确认原地工具栏仍有"自定义尺寸""重新截图"，且工具栏**整条**（抓手与按钮间空白）都显示可移动光标、按住即可拖动、松手吸附、双击空白复位、按 `` ` `` 隐藏/恢复（提示条显示当前键位）；点"窗口编辑"或按 `E` 后确认独立窗口没有截图控制项，但仍可完整标注、变换和保存。
5. **标注与画布**：分别使用文字、画笔、荧光笔、箭头、马赛克、橡皮擦、裁剪；检查参数记忆、图像边界限制、标注二次选择/缩放、撤销重做及小/大图缩放平移。文字标注额外验证：拖动左右边中点改宽度、上下边中点改高度（拖回起点复原、缩放后手感一致），双击二次编辑只作用于该标注且不回写公共配置，插入/编辑对话框显示"自动 ≈ N px"的实际宽高。橡皮擦额外验证：擦过文字/矩形后仍能选中、双击编辑与右键删除；被擦区域右键可"删除此处擦除"（只删经过该点的笔迹）、"删除最近一次擦除"与"清除全部擦除"，工具栏「层级」菜单有后两项；右键勾选"此处同时擦除原图"只影响这一处。
6. **图像输出**：测试任意角度旋转后重置、透明边角、圆角/边框/阴影预览；分别验证保存、贴图、放弃、图片与路径复制开关及通知图片预览。
7. **贴图管理**：贴图片、文件、文字和颜色；替换贴图并确认位置/缩放保留；连续 F3 依次取更早未贴图片，删除文件或关闭中间贴图后再次验证历史跳过/重用。
8. **贴图吸附、多选与分组**：拖动一张贴图靠近另一张贴图的边缘，确认对齐并跟随，再尝试建立反向关系确认不会形成循环；Ctrl 点击选择/取消多张贴图，拖动其中一张确认其余选中项同步移动；在管理面板多选后归组、改名、显隐和关闭所选；删除组应保留贴图。
9. **托盘与打包**：通过托盘菜单打开剪贴板图片/文件图片、新建贴图和设置；验证修改后的快捷键提示。分别用带控制台和无控制台打包启动，检查图标、资源、全局热键权限和启动提示。

### 未支持与待桌面验收

- 贴图互吸、贴图跟随、Ctrl 多选、批量拖动、批量关闭和分组均有自动化回归；桌面拖动手感及跟随视觉效果仍应手动验收。
- 混合 DPI、真实全局热键权限、Win11 原生图片 Toast 呈现和 PyInstaller 打包资源加载需要 Windows 桌面/打包环境验收。

## 设置和数据

设置窗口分为常规、截图、快捷键、保存、输出、编辑器、日志、贴图、剪贴板贴图和主题与外观十类：
每页按使用场景显示带标题的设置组，较长的页面可在页内滚动；同一组件的颜色、线宽及其他参数集中在同一组。设置值在内存中即时更新，配置文件写入合并 250ms 内的连续变化；关闭设置窗口或退出程序时会刷新未写入的最后一次变更。

- **常规**：启动与通知。
- **截图**：截图延迟/光标、截图确认后默认动作（含仅复制）、原地编辑、快速贴图与快速保存、**操作提示**（提示项勾选与拖动排序）、放大镜（开关/尺寸/像素网格）/十字线/标尺、截图取色、窗口与控件识别、遮罩/选区外观及历史范围。悬停识别高亮默认采用 `#168cff` 蓝色、35% 填充不透明度，边线默认同色；遮罩默认采用黑色 `#000000`、60% 不透明度，页面另提供清透蓝、薄荷绿、奶油黄、樱花粉、淡紫等预设，两者都可自定义。
- **快捷键**：全局热键总开关、截图类热键拦截、全局截图/编辑/贴图热键录制、清除和冲突检查。仅在截图遮罩中生效的快捷操作留在截图页，不与全局热键混在一起。
- **保存**：自动截图目录、手动保存目录、可选的按月/按日图片归档、PNG/JPEG/WebP/BMP 格式、质量、透明底色、文件名模板、保存后打开目录，以及保存时是否分别复制图片和路径。
- **输出**：最终图片的透明圆角/半径、边框和阴影；编辑器工具栏"输出 > 外观"弹层也能修改同一配置，实时预览最终结果。
- **编辑器**：默认标注工具、标注颜色/线型/线宽、填充、矩形圆角、荧光笔、文字、马赛克、序号标注、编辑区边框和裁剪框参数。工具栏"更多设置"与本页共用配置，预览会即时刷新。
- **日志**：日志开关、ERROR/WARNING/INFO/DEBUG/TRACE 等级、按小时/每天轮转、按月份创建目录和保存位置。
- **贴图**：透明图像背景模式、默认描边/阴影外观、拖动吸附/跟随窗口、贴图回收站和贴图管理缩略图。
- **剪贴板贴图**：文字卡片字体/字号/颜色/背景/宽度/最大行数；颜色识别、色值标注和色块尺寸；文件卡片路径、展示数量和宽度。
- **主题与外观**：跟随系统、明亮或黑暗主题。

### 设置入口与修改方式

所有页面中的控件会即时写入同一配置并保存。部分设置有多个入口：输出外观既可在"设置 > 保存与输出"调整，也可在编辑器工具栏"输出 > 外观"弹层调整；标注工具当前参数可在工具栏"更多设置"中修改，编辑器页提供相同的默认值和预览。修改任一入口都会同步其他入口和已打开的编辑器。

全局热键在"设置 > 快捷键"修改；截图遮罩内的快速贴图/快速保存键在"设置 > 截图 > 截图快捷操作"修改。设置页底部"恢复本页默认"只重置本页；窗口底部的"恢复全部默认"是最终手段，会先把当前设置备份成同目录的 `settings.bak` 再整体重置，"清理贴图会话"则删除贴图会话文件与私有缓存，方便从空白状态验证。

全局颜色模式位于"设置 > 主题与外观"，提供跟随系统、明亮和黑暗三种选择。它影响应用控件和窗口的调色板，但保留 Windows/Qt 原生控件与 tooltip 外观。设置项放在独立页面，是因为它跨越常规、截图、编辑器和贴图窗口；贴图吸附距离等只影响贴图拖动的偏好仍放在"设置 > 贴图 > 拖动与吸附"。

配置也可以通过设置窗口的 JSON 导入/导出功能备份或迁移；导入时会校验类型、范围和全局热键冲突。

### 配置参数详解

### 通知

Windows 优先显示带缩略图的原生图片 Toast；不可用时回退到应用内预览，其他平台使用应用内预览。
"设置 > 常规 > 启动与通知 > 通知方式"可在 Win11 Toast 与旧版通知之间切换，默认 Win11 Toast；普通状态消息也遵循该选择。Toast 不可用时自动回退；通知仍受总开关及分类开关控制。

Win11 Toast 模式下，截图图片提示缓存本地 PNG 作为 hero 图片，点击可定位已保存文件；普通文字消息也通过 Toast 发送。旧版模式使用应用内图片预览和系统托盘文字提示。无法导入/发送 Toast 时自动回退；通知仍受总开关和对应分类开关控制。

要提供可分析的 UIA 结构，在"设置 > 截图 > 窗口与控件识别"打开"记录 UIA 结构诊断"，再在目标程序上开始截图并悬停/识别目标；复制日志中以"UIA 结构诊断"开头的块。默认日志位于 `logs/YYYY-MM/app.log`（自定义日志目录则以设置为准）。输出最多 60 个节点；名称可能包含标题或文件名，分享前请检查并打码，诊断完成后建议关闭此设置。

标注颜色按画笔、矩形、椭圆、箭头、荧光笔和文字分别保存；工具栏"更多设置"显示当前工具对应颜色，设置项位于"设置 > 编辑器"内对应工具的专属组。画笔、矩形、椭圆分别显示独立预览。原地窗口编辑与独立单图编辑使用同一组独立颜色配置。截图选区转为贴图时，贴图图像左上角对齐选区原屏幕位置；快速贴图同样保留选区位置。普通图片编辑和剪贴板贴图没有原截图位置时，贴图图像中心默认对准鼠标指针。

### 编辑器结构

原地编辑器和独立编辑器复用标注画布、工具栏与输出效果，但保留各自的窗口生命周期适配：原地编辑依附截图遮罩和选区几何，独立编辑器负责普通窗口、多图和文件操作。调整共享控件时需分别验证两种上下文；避免复制两套画布/保存实现，也不要把两种窗口关闭和截图路由强行合并。

### 配置参数详解

以下参数名与 JSON 配置键一致。默认值是首次启动值；设置页修改后立即保存。参数表按设置页排列，每页内的控件按分组顺序列出；具体分组名称与界面一致。`hotkeys` 是动作到快捷键的字典，完整默认值见上方全局热键表。`last_capture_rect` 由程序记录上次选区位置和大小，不是用户设置。

设置页面内分组：常规页为"启动与通知"；快捷键页为"全局热键""截图快捷键""编辑快捷键""贴图快捷键"；截图页为"截图时机""截图内容""截图后""截图快捷操作""定位辅助""取色""窗口与控件识别""遮罩与选区""历史"，定位辅助、候选框、遮罩选区、取色预览分别位于相应组内；编辑器页为"默认工具""箭头""画笔""矩形""椭圆""橡皮擦""荧光笔""文字""马赛克""序号标注""编辑区边框""裁剪框"，"文字"组含字体/字号/文字宽度（0 表示按内容自动换行）/文字高度（0 表示随内容自动增长）/行距/对齐/格式/背景，画笔、矩形、椭圆、橡皮擦和序号标注各自带独立预览；贴图页为"透明图像背景""贴图外观""拖动与吸附""回收站""贴图管理窗口"；剪贴板贴图页为"文字贴图""颜色贴图""文件贴图"，各类卡片预览位于对应组内；主题与外观页为"应用主题"；保存与输出页包含"输出图像外观""自动保存""手动保存""图片归档""文件与目录""手动保存后复制"；日志页为"日志记录"。

### 贴图会话与吸附设置

本节只记录贴图的**持久化数据与吸附/外观默认值**；逐项操作、透明背景、吸附行为和贴图管理面板见"操作手册 > 贴图窗口"。

**吸附与跟随设置**（"设置 > 贴图 > 拖动与吸附"）：可关闭自动吸附，将触发距离设为 1–40 逻辑像素（默认 8），选择只吸附屏幕/工作区边缘、只吸附窗口与贴图边缘或两者都吸附。窗口跟随与贴图跟随可分别开关；跟随刷新间隔可设为 30–1000 毫秒（默认 120）。拖动时按住 `Alt` 只临时绕过本次吸附，不会修改这些持久设置。

**会话保存的字段**：屏幕位置、实际宽高、相对原图的缩放倍率、旋转角度、透明度、锁定/置顶/点击穿透状态、分组归属和有效吸附关系。拖动和缩放后的状态经短暂防抖写入，退出时再强制刷新；下次启动按这些字段恢复窗口。源文件被移动、删除或无法读取时跳过对应贴图，不会恢复空白窗口。

**分组与关闭顺序**：删除组或取消归组只清除分组关系，不关闭窗口也不删除源图片；关闭组会在操作完成前同步保存最终会话状态，并取消此前排队的防抖写入，避免重启时重新恢复已关闭成员。

**外观默认值**（"设置 > 贴图 > 贴图外观"）：描边开关/颜色/宽度、阴影开关/颜色/强度、选中光晕开关与强度（0–100%，默认 30%）只决定新建贴图的默认值；单张贴图仍可在右键菜单中单独切换描边、阴影、透明度和背景模式。

### 通知

Windows 截图提示优先使用带缩略图的原生图片 Toast；无法导入或发送时回退到应用内非激活预览，其他平台使用应用内预览。截图通知点击可定位已保存文件；贴图和一般状态使用系统托盘文字通知，点击贴图通知可打开贴图管理窗口。截图进入编辑器时，初始保存并入现有截图提示；后续用户主动保存仍单独显示保存结果。

截图图片提示在 Windows 上优先使用 Win11 原生图片 Toast，缓存本地 PNG 作为 hero 图片；点击 Toast 会定位已经保存的文件。Toast 线程不会阻塞 Qt 界面，点击事件切回 Qt 主线程读取最新文件目标，因此截图刚完成、初始保存稍后才结束时也能使用正确路径。无法导入/发送原生 Toast 时回退到应用内图片预览；非 Windows 平台始终使用应用内预览。「仅复制到剪贴板」等复制类反馈为保证复制内容可见，一律使用应用内本地缩略图预览，不依赖 Win11 Toast 附带 hero 图（后者经常不显示缩略图）。贴图和一般状态继续使用托盘文字提示。通知是否出现仍受"设置 > 常规 > 通知总开关"和对应分类开关控制。

## 技术指南

应用入口为 `main.py`。`core/` 负责配置、路径、图像与应用生命周期；`screenshot/` 管理截图遮罩、选区及原地编辑；`editor/` 提供共享画布、工具栏和独立编辑窗口；`sticker/` 管理置顶贴图、历史导航与会话恢复；`ui/` 放置托盘、设置、通知等界面；`hotkey/` 和 `logger/` 分别封装全局快捷键与日志。

改动截图流程时，同时检查原地编辑、独立窗口、多选区和多显示器路径；改动贴图状态时检查创建、关闭、重启恢复及旧 session 兼容。高频移动、缩放和定时保存只记录状态变化或限频错误，不逐次输出日志；等级和敏感数据要求见项目根目录 `AGENTS.md`。未捕获异常（Qt 事件/槽、主线程顶层、子线程）由全局兜底钩子捕获并写入 `logs/<YYYY-MM>/app.log`，即使日志处理器尚未配置（启动期崩溃）也能留痕，便于排错。

### 回归测试

所有回归用例集中在单个文件 [`tests/test_core.py`](tests/test_core.py)，一个 `CoreTests(unittest.TestCase)` 类内按功能分区（配置、截图遮罩、选区、编辑器、标注、贴图、剪贴板、设置页、打包相关等）。用例名即验收点，读名字就能知道覆盖了什么（例如 `test_capture_operation_tips_are_centered_on_each_monitor`）。命令都在**项目根目录**执行：

```powershell
# 全部用例（建议先看末尾的 Ran N tests / OK 或 FAILED 行）
.\.venv\Scripts\python -m unittest tests.test_core

# 单个用例：模块.类.方法
.\.venv\Scripts\python -m unittest tests.test_core.CoreTests.test_mask_color_presets_and_legacy_theme_migration -v

# 按关键字筛选（匹配测试名子串，适合只跑某一块）
.\.venv\Scripts\python -m unittest tests.test_core -k capture      # 截图相关
.\.venv\Scripts\python -m unittest tests.test_core -k sticker      # 贴图相关
.\.venv\Scripts\python -m unittest tests.test_core -k hover        # 悬停识别/候选框
```

用例是标准 `unittest.TestCase`，推荐用上面的 `unittest` 运行器（依赖清单不含 pytest）；本机若已装 pytest，`pytest tests/test_core.py -k capture` 也能收集同一批用例。命名习惯是 `test_<对象>_<行为>`，新增用例请沿用，方便用 `-k` 成组筛选。

运行约定：

- **工作目录必须是仓库根目录**：用例按包路径 `tests.test_core` 导入，且多处使用相对资源与临时目录。
- **尽量构造真实对象**：优先实例化 `MaskWindow`、`EditorWindow`、`ToolbarWidget`、`ConfigManager` 等真实组件，只在无法构造（如只验证绘制调用）时才用 `Mock` 替换 `QPainter`。例如提示条相关用例用 `Mock` 灌入 `fontMetrics` 的宽度函数，就能确定性地断言条宽与居中，而不依赖真实字体。
- **窗口类用例不依赖真实屏幕**：`setUpClass` 创建唯一的 `QApplication`（`QApplication.instance() or QApplication([])`），不注册全局热键、不读真实显示器几何。需要在无桌面环境（CI/远程）跑时设置 `QT_QPA_PLATFORM=offscreen`；离屏环境 DPR 为 1、逻辑坐标与设备像素 1:1，按固定坐标采样是确定的。需要真实像素时用 `QImage` + `QPainter` 自己画再取 `pixelColor`，避免依赖屏幕抓取。
- **覆盖边界**：用例不覆盖 Windows 原生 Toast、真实全局热键权限、真实混合 DPI 与系统窗口管理器行为，这些仍需桌面手动验收（见"未支持与待桌面验收"）。
- **几何断言读控件而非截图**：工具栏、按钮、网格布局用 `geometry()`、`grid.getItemPosition()`、`spacing()` 等直接断言，比像素比对稳定。
- **配置用例用临时目录**：`tempfile.TemporaryDirectory()` + `ConfigManager(path)`，不读写用户真实配置；默认值断言直接对比 `DEFAULTS`。
- **跑测时不要同时运行程序实例**：托盘程序会占用剪贴板、注册全局热键并持有贴图窗口，容易让相关用例偶发失败。
- **重批次拆半跑**：遮罩/采集自检这一大组（`-k mask -k capture -k notification -k self_check`，约 80 项）在本机会**偶发**进程级崩溃（退出码 `0xC0000374` 堆损坏 / `0xC0000409` / `0xC0000354`）。这不是用例或代码的问题：用 `git worktree` 干净副本对照，**只加 4 条纯空转用例**同样复现，且同一组合时崩时不崩。把大组按用例名字母序拆成 8–16 条一组都能稳定通过，建议这类大组一律拆小运行。另有两条 Windows 平台敏感的既有失败（放大镜首次悬停可见性、原地编辑键盘微调焦点），HEAD 干净副本同样失败，与近期改动无关。

维护约定：

- **行为变更必须同步更新断言**：改默认值、改控件尺寸、改文案或改调用签名后，对应用例要一起改（例如紧凑工具栏把按钮 30px 改 24px、竖向间距 1 改 0，提示条贴顶后取样点也要跟着改）。
- **新增功能至少补一条定向用例**，并在这次改动的"调整记录"里写明验证方式。
- **不要为了变绿删用例**：历史上有过误删测试文件的情况，已回滚；测试文件属于源码的一部分。
- **判读失败先看是否既有**：本机存在与显示器几何、剪贴板、Toast 相关的既有环境失败。判断新失败是否由本次改动引入，可用干净副本对照同一组用例：

  ```powershell
  git worktree add .tmp-baseline HEAD
  cd .tmp-baseline
  ..\.venv\Scripts\python -m unittest tests.test_core -k capture
  cd ..
  git worktree remove .tmp-baseline --force
  ```

- **自动化不能替代桌面验收**：混合 DPI、真实全局热键权限、Win11 原生 Toast 与打包资源加载仍需 Windows 桌面环境手动验收。

### PyInstaller 打包

程序入口为 `main.py`，仅面向 Windows（依赖 `pywin32`、`win11toast`、`uiautomation` 与 `ctypes.windll`，见 [requirements.txt](requirements.txt) 中带 `sys_platform == "win32"` 的包）。仓库已消除动态导入、相对导入与隐式导入，所有模块均为静态绝对导入，PyInstaller 可静态分析识别；若个别模块仍报缺失，追加 `--hidden-import=<模块全名>` 即可。

推荐在 PowerShell 中于项目根目录执行（先激活 `.venv`）：

```powershell
# 1) 带控制台 + 单文件：便于排错，启动慢、单一 exe 便于分发
pyinstaller --name ScreenSnap --console --onefile --icon icon.ico --add-data "icon.ico;." --add-data "icon.png;." main.py

# 2) 带控制台 + 目录：便于排错，启动快、依赖散落在 dist 文件夹
pyinstaller --name ScreenSnap --console --onedir --icon icon.ico --add-data "icon.ico;." --add-data "icon.png;." main.py

# 3) 不带控制台 + 单文件：面向最终用户，无黑框、单一 exe
pyinstaller --name ScreenSnap --windowed --onefile --icon icon.ico --add-data "icon.ico;." --add-data "icon.png;." main.py

# 4) 不带控制台 + 目录：面向最终用户，无黑框、启动最快
pyinstaller --name ScreenSnap --windowed --onedir --icon icon.ico --add-data "icon.ico;." --add-data "icon.png;." main.py
```

参数含义：

- `--name ScreenSnap`：输出可执行文件名（`ScreenSnap.exe`）。
- `--console` / `--windowed`（等价于 `--noconsole`）：是否保留黑色控制台窗口。调试阶段用 `--console` 可看到标准输出、日志与异常回溯；发布给普通用户用 `--windowed`，否则托盘程序会多出一个控制台窗口。两者都不会影响程序自身的日志文件（`logs/`）。
- `--onefile` / `--onedir`：`-onefile` 把所有依赖压缩进单个 exe，分发方便但启动更慢、临时解包到 `%TEMP%`；`-onedir` 保留依赖文件夹，启动快、便于排查缺失文件，分发时需连同整个 `dist/ScreenSnap` 目录一起打包。
- `--icon icon.ico`：exe 与任务栏图标；托盘图标仍由运行时的 `icon.ico`/`icon.png` 提供（已通过 `--add-data` 打入）。
- `--add-data "源;目标"`：把图标拷进打包根，运行时经 `sys._MEIPASS` 读取；若换成文件夹资源，按相同方式追加。

构建产物在 `dist/ScreenSnap`（目录模式）或 `dist/ScreenSnap.exe`（单文件模式）。增量构建建议加 `--clean` 避免旧缓存干扰。Windows 全局热键、原生 Toast 与混合 DPI 等仍应在目标 Windows 环境最终验收；源码测试通过不能代替真实桌面打包验收。

## 已知限制

- 全局快捷键依赖 Windows 键盘钩子；前后台进程权限等级不一致时，热键可能无法生效。先检查"设置 > 快捷键"绑定和总开关，再让程序与目标窗口以相同权限运行。
- 点击穿透会让鼠标事件落到后方窗口，贴图本身无法接收右键；使用 `Ctrl+Shift+T` 恢复贴图交互。
- 多显示器混合 DPI、跨屏选区、原生 Toast 点击回调和系统窗口吸附受 Windows 桌面状态影响，自动化离屏测试不能覆盖所有驱动、通知设置及权限组合。
- 贴图会话引用自动保存目录中的图像；若源文件被移动、删除或无法读取，重启时会跳过该贴图，不会创建空白窗口。

### 2026-10-04 提示条改为跟随放大镜、逐项可开关可排序；放大镜尺寸可调

- **提示条不再贴屏顶，改为跟着放大镜走**：原先贴屏幕最上沿居中，鼠标移上去还得整条隐藏（"移入隐藏、移出恢复"）。现在整条画在放大镜框**下方**，下方放不下就画上方；放大镜关闭或被模态/弹出菜单遮挡时，仍按同一避让规则算出框，提示继续跟着光标显示，**鼠标避让逻辑整体删除**（`info_hidden`/`info_bar_rects` 与 `paint_info(hidden=...)` 一并移除）。`paint_info` 改为接收放大镜框（`anchor`）与提示项列表，返回提示条矩形。
- **提示项可逐项开关、可排序**：新增 `capture_hint_order`（列表即开关与顺序，默认 = 全部提示项）与 `config.HINT_ITEMS`（id → 名称，唯一来源）；遮罩的 `capture_hint_items()` 按该顺序产出文案，当前阶段不适用的项留空（绘制端跳过，不会出现"提示了用不上的键"）。设置页新增「截图 > 操作提示」分组：`HintOrderList` 控件勾选=显示、拖动=顺序，值直接写入配置；`恢复本页默认` 会把它一起还原（设置页基类的 `sync_controls` 增加 `set_value` 兜底，支持这类复合控件）。

### 2026-10-03 缩放「默认等比 + 按住键自由拉伸」在旋转后依然成立

- **现象**：加了旋转之后，四角拖动「默认等比不变形、按住 `Ctrl`/`Alt`/`Shift`/`Space` 任一自由拉伸」的规则似乎失效（按了键仍是等比）。

- **验证**：新增 `test_corner_resize_keeps_aspect_after_rotation_and_free_with_modifier`（0°/30°/90° 下用非等比位移拖 `se`：未按修饰键时横纵缩放比一致、按下 `Ctrl` 时不一致）；原有 `test_annotation_corner_resize_is_uniform_by_default_and_free_with_modifier`、缩放锚点、旋转项缩放等用例均通过。

### 2026-10-03 被擦除层覆盖的标注仍可选中/编辑/删除

- **现象**：文字、矩形等标注被橡皮擦擦过后无法再次编辑，右键「删除标注」也没反应（擦除只是把像素镂空，图元本身仍在，应当照常可选中与编辑）。
- **根因**：编辑与删除两条入口都用 `scene_data.itemAt()` 做命中测试，而擦除层 `EraseMaskItem` 的 z 高于标注且覆盖其上，`itemAt()` 返回的是擦除层（它不可选、不接受鼠标）。于是双击时被当成「非文字标注」、右键菜单作用到擦除层上——`remove_selected()` 因没有选中项直接返回，表现为「删不掉」。
- **修正**：新增 `AnnotationCanvas.annotation_at(point)`，按 z 降序用 `items()` 命中并跳过底图与擦除层，只返回真正的标注图元；双击编辑/删除、右键菜单、以及「空白处拖动框选」的空白判定统一改用它。擦除层仍不可选中、不接受鼠标，渲染与非破坏擦除行为不变。
- **验证**：新增 `test_erased_annotation_still_editable_and_deletable`：在文字与矩形上各擦一段（擦除层 z 高于标注）后，断言命中测试返回标注本身、单击可选中并能删除、双击被擦矩形可删除且可撤销、双击被擦文字打开编辑对话框、右键菜单作用于该标注且删除可撤销。擦除/双击/右键批次 26 项、选中/点击/菜单批次 77 项、文字/缩放/快照批次 48 项均通过。

### 2026-10-03 擦除可精确删除（按笔迹，而不是整层清空）

- **需求**：此前擦除只能靠撤销回退，步骤一多就要连带回滚其后的所有标注；擦除内容应当可以单独删除。
- **用户可见变化**：工具栏「层级」菜单提供「删除最近一次擦除 / 清除全部擦除」；在**被擦除的区域**（该处没有标注）右键，提供「删除此处擦除 / 删除最近一次擦除 / 清除全部擦除」。删除只作用于擦除内容：其下方被擦掉的标注像素随即恢复显示，之后画的标注一条不动；删除同样进历史，可撤销/重做。
- **笔迹级粒度**：擦除笔迹默认会合并进同一擦除层（只有"擦除后又画了新标注"才分层），若按整层删除，「此处/最近一次」都会退化成清空全部。为此擦除层改为**按每次拖动记录笔迹分组**（`EraseMaskItem.strokes`，遮罩始终由笔迹渲染、可随时重绘）：`erase_one` 只删最近一次拖动的笔迹，`erase_at` 只删笔迹经过该点的那几次擦除，`erase_clear` 才清空所有擦除层；某层笔迹被删空后自动移除。快照/撤销同步携带笔迹记录。
- **实现边界**：`EraseMaskItem` 新增 `add_stroke` / `render` / `drop_groups` / `group_ids` / `groups_near`（含点到线段距离判定），`erase_segment` 改为写入分组笔迹，按下时递增分组编号；`AnnotationCanvas` 新增 `erased_at(point)`（按遮罩像素判断该点是否被擦过）、`erase_layer(action, point)` 与 `erase_menu`/`show_erase_menu`，两种编辑器的 `execute` 都接入 `erase_one`/`erase_clear`。擦除层仍不参与选中、不接受鼠标，命中测试继续跳过它（仅右键处没有标注时才给擦除菜单），非破坏擦除与渲染逻辑不变。
- **验证**：新增 `test_erase_at_and_last_remove_only_their_own_stroke`（同一擦除层内两笔互不相连的擦除：`erase_at` 只恢复被点中那一笔的像素、另一笔仍被擦；`erase_one` 再删剩下一笔；撤销逐次恢复）、`test_erase_layer_can_be_deleted_like_a_layer`（跨层：`erase_one`/`erase_at`/`erase_clear`，标注数量不变，撤销/重做，渲染像素用填充矩形校验）、`test_right_click_erased_area_shows_erase_layer_menu`（右键被擦空白处弹出菜单、三项文案、首项生效并可撤销）与 `test_layer_menu_deletes_erase_layer_in_both_editors`（两种编辑器端到端）。擦除相关 17 项、擦除/快照/撤销/渲染 32 项、选中/菜单/文字 100 项通过；另有 2 项既有失败（选项面板已并入第 13 行的旧「圆角半径」行、放大镜初始可见性）与本改动无关。
